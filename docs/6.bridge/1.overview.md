::note
新しい Nuxt 3 プロジェクトを始める場合は、このセクションをスキップして [Nuxt 3 インストール](/docs/getting-started/introduction) に進んでください。
::

::warning
Nuxt Bridge は Nuxt 3 と同等の機能を提供します（[ドキュメント](/docs/guide/concepts/auto-imports)）が、[`useAsyncData`](/docs/api/composables/use-async-data) と [`useFetch`](/docs/api/composables/use-fetch) Composable が利用できないなど、いくつかの制限があります。詳細はこのページの他の部分をお読みください。
::

Bridge は、Nuxt モジュールをインストールして有効にするだけで、新しい Nuxt 3 機能の多くを体験できる前方互換性レイヤーです。

Nuxt Bridge を使用することで、プロジェクトが Nuxt 3 に（ほぼ）準備ができていることを確認でき、Nuxt 3 への移行を段階的に進めることができます。

## 最初のステップ

### Nuxt 2 のアップグレード

開発サーバー（`nuxt dev`）が実行されていないことを確認し、パッケージロックファイル（`package-lock.json` と `yarn.lock`）を削除し、最新の Nuxt 2 バージョンをインストールします：

```diff [package.json]
- "nuxt": "^2.16.3"
+ "nuxt": "^2.17.3"
```

その後、依存関係を再インストールします：

::code-group{sync="pm"}

```bash [npm]
npm install
```

```bash [yarn]
yarn install
```

```bash [pnpm]
pnpm install
```

```bash [bun]
bun install
```

::

::note
インストールが完了したら、進める前に開発と本番の両方のビルドが期待通りに動作していることを確認してください。
::

### Nuxt Bridge のインストール

`@nuxt/bridge` と `nuxi` を開発依存関係としてインストールします：

::code-group{sync="pm"}

```bash [npm]
npm install -D @nuxt/bridge nuxi
```

```bash [yarn]
yarn add --dev @nuxt/bridge nuxi
```

```bash [pnpm]
pnpm add -D @nuxt/bridge nuxi
```

```bash [bun]
bun add -D @nuxt/bridge nuxi
```

::

### `nuxt.config` の更新

設定ファイルで `module.exports`、`require`、`require.resolve` などの CommonJS 構文を使用しないようにしてください。これらは間もなく非推奨となり、サポートされなくなります。

代わりに静的 `import`、動的 `import()`、`export default` を使用できます。[`nuxt.config.ts`](/docs/guide/directory-structure/nuxt-config) にリネームして TypeScript を使用することも可能で、推奨されています。

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: false
})
```

### コマンドの更新

`nuxt` コマンドを `nuxt2` コマンドに変更する必要があります。

```diff
{
  "scripts": {
-   "dev": "nuxt",
+   "dev": "nuxt2",
-   "build": "nuxt build",
+   "build": "nuxt2 build",
-   "start": "nuxt start",
+   "start": "nuxt2 start"
  }
}
```

ここで一度 `nuxt2` を実行してみてください。アプリケーションが以前と同じように動作することがわかります。

（'bridge' が false に設定されている場合、アプリケーションは以前と同じように変更なしで動作します。）

## CommonJS から ESM への移行

Nuxt 3 は TypeScript と ECMAScript モジュールをネイティブサポートしています。詳細とアップグレードについては [ネイティブ ES モジュール](/docs/guide/concepts/esm) をチェックしてください。
