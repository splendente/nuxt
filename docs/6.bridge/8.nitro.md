---
title: Nitro
description: 'Nuxt Bridge で Nuxt 2 アプリケーションに Nitro を有効化します。'
---

## モジュールの削除

- `@nuxt/nitro` を削除: Bridge が同じ機能を注入します

## 設定の更新

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    nitro: true
  }
})
```

## スクリプトの更新

Nuxt がビルド出力として Nitro サーバーを生成するようになったことを反映させるために、`package.json` 内のスクリプトも更新する必要があります。

### Nuxi のインストール

`nuxi` を開発依存関係としてインストールします:

::code-group{sync="pm"}

```bash [npm]
npm install -D nuxi
```

```bash [yarn]
yarn add --dev nuxi
```

```bash [pnpm]
pnpm add -D nuxi
```

```bash [bun]
bun add -D nuxi
```

::

### Nuxi

Nuxt 3 は新しい Nuxt CLI コマンド [`nuxi`](/docs/api/commands/add) を導入しました。Nuxt Bridge からのより良いサポートを活用するために、次のようにスクリプトを更新します:

```diff
{
  "scripts": {
-   "dev": "nuxt",
+   "dev": "nuxi dev",
-   "build": "nuxt build",
+   "build": "nuxi build",
-   "start": "nuxt start",
+   "start": "nuxi preview"
  }
}
```

::tip
`nitro: false` の場合は、`nuxt2` コマンドを使用してください。
::

### 静的ターゲット

`nuxt.config` で `target: 'static'` を設定している場合は、ビルドスクリプトを `nuxi generate` に更新する必要があります。

```json [package.json]
{
  "scripts": {
    "build": "nuxi generate"
  }
}
```

### サーバーターゲット

その他のすべての状況では、`nuxi build` コマンドを使用できます。

```json [package.json]
{
  "scripts": {
    "build": "nuxi build",
    "start": "nuxi preview"
  }
}
```

## ビルドされた Nitro フォルダを Git から除外

`.output` フォルダを `.gitignore` ファイルに追加します。

## すべてがうまくいくことを確認

✔️ `nuxi dev` と `nuxi build`（または `nuxi generate`）で試して、すべてがうまくいくかどうかを確認してください。
