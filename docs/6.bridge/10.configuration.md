## 機能フラグ

bridge の一部機能を無効にするか、あまり安定していない機能をオプトインすることができます。通常の状況では、デフォルトを使い続けるのが最良です！

最新のデフォルトについては [bridge/src/module.ts](https://github.com/nuxt/bridge/blob/main/packages/bridge/src/module.ts) を確認できます。

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'
export default defineNuxtConfig({
  bridge: {

    // -- オプトイン機能 --

    // webpack 4 の代わりに Vite をバンドラーとして使用
    // vite: true,

    // Nuxt 3 互換 useHead を有効化
    // meta: true,

    // definePageMeta マクロを有効化
    // macros: {
    //   pageMeta: true
    // },

    // esbuild で TypeScript のトランスパイルを有効化
    // typescript: {
    //   esbuild: true
    // },

    // -- デフォルト機能 --

    // Nitro の代わりにレガシーサーバーを使用
    // nitro: false,

    // Nuxt 3 互換 `nuxtApp` インターフェースを無効化
    // app: false,

    // Composition API サポートを無効化
    // capi: false,

    // ... またはレガシー Composition API サポートのみを無効化
    // capi: {
    //   legacy: false
    // },

    // モジュールをトランスパイルしない
    // transpile: false,

    // <script setup> サポートを無効化
    // scriptSetup: false,

    // Composable の自動インポートを無効化
    // imports: false,

    // モジュールの非互換性について警告しない
    // constraints: false
  },

  vite: {
    // Vite の設定
  }
})
```

## 各オプションの移行

### router.base

```diff
export default defineNuxtConfig({
- router: {
-   base: '/my-app/'
- }
+ app: {
+   baseURL: '/my-app/'
+ }
})
```

### build.publicPath

```diff
export default defineNuxtConfig({
- build: {
-   publicPath: 'https://my-cdn.net'
- }
+ app: {
+   cdnURL: 'https://my-cdn.net'
+ }
})
```
