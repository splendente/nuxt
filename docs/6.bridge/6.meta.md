`head` でコンポーネントの状態にアクセスする必要がある場合は、[`useHead`](/docs/api/composables/use-head) を使用するように移行する必要があります。

Options API を使用する必要がある場合は、`defineNuxtComponent` を使用する際に使用できる `head()` メソッドがあります。

## 移行

### `bridge.meta` の設定

```js
import { defineNuxtConfig } from '@nuxt/bridge'
export default defineNuxtConfig({
  bridge: {
    meta: true,
    nitro: false // Nitro への移行が完了している場合は、true に設定
  }
})
```

### head プロパティの更新

`nuxt.config` で、`head` を `meta` にリネームします。（オブジェクトには重複除去のための `hid` キーがなくなったことに注意してください。）

::code-group

```ts [Nuxt 2]
export default {
  head: {
    titleTemplate: '%s - Nuxt',
    meta: [
      { charset: 'utf-8' },
      { name: 'viewport', content: 'width=device-width, initial-scale=1' },
      { hid: 'description', name: 'description', content: 'Meta description' }
    ]
  }
}
```

```ts [Nuxt 3]
export default defineNuxtConfig({
  app: {
    head: {
      titleTemplate: '%s - Nuxt',
      meta: [
        { charset: 'utf-8' },
        { name: 'viewport', content: 'width=device-width, initial-scale=1' },
        { name: 'description', content: 'Meta description' }
      ]
    }
  }
})
```

::

## `useHead` Composable

Nuxt Bridge は、新しい [`useHead`](/docs/api/composables/use-head) Composable でアクセスできる新しい Nuxt 3 メタ API を提供します。

```vue
<script setup lang="ts">
useHead({
  title: 'My Nuxt App',
})
</script>
```

::tip
この [`useHead`](/docs/api/composables/use-head) Composable は、`<head>` を操作するために内部で `@unhead/vue`（`vue-meta` ではなく）を使用しています。
::

::warning
競合する可能性があるため、[`useHead`](/docs/api/composables/use-head) に加えてネイティブの Nuxt 2 `head()` プロパティを使用しないことをお勧めします。
::

この Composable の使用方法についての詳細は、[ドキュメント](/docs/getting-started/seo-meta)を参照してください。

## Options API

```vue
<script>
// Options API `head` メソッドを使用する場合は、`defineNuxtComponent` を使用する必要があります
export default defineNuxtComponent({
  head (nuxtApp) {
    // `head` は nuxt app を受け取りますが、コンポーネントインスタンスにはアクセスできません
    return {
      meta: [{
        name: 'description',
        content: 'これは私のページの説明です。'
      }]
    }
  }
})
</script>
```

::warning
破壊的変更の可能性: `head` は nuxt app を受け取りますが、コンポーネントインスタンスにはアクセスできません。`head` 内のコードが `this` または `this.$data` を通じてデータオブジェクトにアクセスしようとする場合は、`useHead` Composable に移行する必要があります。
::

## タイトルテンプレート

関数を使用したい場合（完全な制御のため）、これは nuxt.config で設定できないため、代わりに `/layouts` ディレクトリ内で設定することをお勧めします。

```vue [layouts/default.vue]
<script setup lang="ts">
useHead({
  titleTemplate: (titleChunk) => {
    return titleChunk ? `${titleChunk} - サイトタイトル` : 'サイトタイトル';
  }
})
</script>
```
