Nuxt では、アプリケーションから選択したページをビルド時にレンダリングできます。Nuxt は、リクエストがあったときに動的に生成するのではなく、事前構築されたページを提供します。

:read-more{title="Nuxt rendering modes" to="/docs/guide/concepts/rendering"}

## クロールベースの事前レンダリング

[Nitro](/docs/guide/concepts/server-engine) クローラーを使用してアプリケーションを構築および事前レンダリングするには、[`nuxt generate` コマンド](/docs/api/commands/generate) を使用します。このコマンドは、`nitro.static` オプションを `true` に設定した `nuxt build` 、または `nuxt build --prerender` の実行と似ています。

これによりサイトが構築され、Nuxt インスタンスが立ち上がり、デフォルトではルートページ `/` と、そこからリンクされたサイトのすべてのページ、それらからリンクされたサイトのすべてのページ、というように事前レンダリングされます。

::code-group{sync="pm"}

```bash [npm]
npx nuxt generate
```

```bash [yarn]
yarn nuxt generate
```

```bash [pnpm]
pnpm nuxt generate
```

```bash [bun]
bun x nuxt generate
```

::

現在、`.output/public` ディレクトリを任意の静的ホスティングサービスにデプロイするか、`npx serve .output/public` でローカルでプレビューできます。

Nitro クローラーの動作：

1. アプリケーションのルートルート（`/`）、`~/pages` ディレクトリ内の非動的ページ、および `nitro.prerender.routes` 配列内のその他のルートの HTML を読み込みます。
2. HTML と `payload.json` を `~/.output/public/` ディレクトリに保存し、静的に提供されるようにします。
3. HTML 内のすべてのアンカータグ（`<a href="...">`）を見つけて他のルートにナビゲートします。
4. クロールするアンカータグがなくなるまで、見つかった各アンカータグに対してステップ 1-3 を繰り返します。

これは、発見可能なページにリンクされていないページは自動的に事前レンダリングできないため、理解しておくことが重要です。

::read-more{to="/docs/api/commands/generate#nuxt-generate"}
`nuxt generate` コマンドについて詳しく読む。
::

### 選択的事前レンダリング

`nuxt.config` ファイルで、[Nitro](/docs/guide/concepts/server-engine) がビルド中に取得および事前レンダリングするルートを手動で指定したり、`/dynamic` のように事前レンダリングしたくないルートを無視したりできます：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  nitro: {
    prerender: {
      routes: ["/user/1", "/user/2"],
      ignore: ["/dynamic"],
    },
  },
});
```

`/sitemap.xml` や `/robots.txt` など、クローラーが発見できないルートセットを事前レンダリングするために、`crawlLinks` オプションと組み合わせることができます：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  nitro: {
    prerender: {
      crawlLinks: true,
      routes: ["/sitemap.xml", "/robots.txt"],
    },
  },
});
```

`nitro.prerender` を `true` に設定することは、`nitro.prerender.crawlLinks` を `true` に設定することと似ています。

::read-more{to="https://nitro.build/config#prerender"}
Nitro ドキュメントで事前レンダリングについて詳しく読む。
::

最後に、routeRules を使用して手動で設定することもできます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    // prerender を true に設定して事前レンダリングされるように設定
    "/rss.xml": { prerender: true },
    // false に設定して事前レンダリングをスキップするように設定
    "/this-DOES-NOT-get-prerendered": { prerender: false },
    // /blog 以下のすべてが、他のページからリンクされている限り
    // 事前レンダリングされます
    "/blog/**": { prerender: true },
  },
});
```

::read-more{to="https://nitro.build/config/#routerules"}
Nitro の `routeRules` 設定について詳しく読む。
::

簡略表記として、[`defineRouteRules`](/docs/api/utils/define-route-rules) を使用してページファイルでこれを設定することもできます。

::read-more{to="/docs/guide/going-further/experimental-features#inlinerouterules" icon="i-lucide-star"}
この機能は実験的であり、使用するには `nuxt.config` で `experimental.inlineRouteRules` オプションを有効にする必要があります。
::

```vue [pages/index.vue]
<script setup>
// またはページレベルで設定
defineRouteRules({
  prerender: true,
});
</script>

<template>
  <div>
    <h1>Homepage</h1>
    <p>ビルド時に事前レンダリングされました</p>
  </div>
</template>
```

これは以下に変換されます：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  routeRules: {
    "/": { prerender: true },
  },
});
```

## ランタイム事前レンダリング設定

### `prerenderRoutes`

Nitro が事前レンダリングするようにより多くのルートを追加するために、[Nuxt コンテキスト](/docs/guide/going-further/nuxt-app#the-nuxt-context)内のランタイムでこれを使用できます。

```vue [pages/index.vue]
<script setup>
prerenderRoutes(["/some/other/url"]);
prerenderRoutes("/api/content/article/my-article");
</script>

<template>
  <div>
    <h1>これは事前レンダリング時に他のルートを事前レンダリング用に登録します</h1>
  </div>
</template>
```

:read-more{title="prerenderRoutes" to="/docs/api/utils/prerender-routes"}

### `prerender:routes` Nuxt フック

これは、追加のルートが登録されるために事前レンダリング前に呼び出されます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    async "prerender:routes"(ctx) {
      const { pages } = await fetch("https://api.some-cms.com/pages").then(
        (res) => res.json(),
      );
      for (const page of pages) {
        ctx.routes.add(`/${page.name}`);
      }
    },
  },
});
```

### `prerender:generate` Nitro フック

これは事前レンダリング中の各ルートに対して呼び出されます。事前レンダリングされる各ルートの細かい処理に使用できます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  nitro: {
    hooks: {
      "prerender:generate"(route) {
        if (route.route?.includes("private")) {
          route.skip = true;
        }
      },
    },
  },
});
```
