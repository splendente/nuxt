## `app.vue`

![app.vue ファイルはアプリケーションのエントリーポイントです](/assets/docs/getting-started/views/app.svg)

デフォルトで、Nuxt はこのファイルを**エントリーポイント**として扱い、アプリケーションのすべてのルートでその内容をレンダリングします。

```vue [app.vue]
<template>
  <div>
   <h1>ホームページへようこそ</h1>
  </div>
</template>
```

::tip
Vue に慣れている方は、通常 Vue アプリを作成する `main.js` がどこにあるのか疑問に思うかもしれません。Nuxt ではこれを裏側で自動的に処理します。
::

## コンポーネント

![コンポーネントは再利用可能な UI の部品です](/assets/docs/getting-started/views/components.svg)

ほとんどのコンポーネントは、ボタンやメニューのようなユーザーインターフェースの再利用可能な部品です。Nuxt では、これらのコンポーネントを [`components/`](/docs/guide/directory-structure/components) ディレクトリに作成すると、明示的にインポートしなくてもアプリケーション全体で自動的に利用できます。

::code-group

```vue [app.vue]
<template>
  <div>
    <h1>ホームページへようこそ</h1>
    <AppAlert>
      これは自動インポートされたコンポーネントです。
    </AppAlert>
  </div>
</template>
```

```vue [components/AppAlert.vue]
<template>
  <span>
    <slot />
  </span>
</template>
```

::

## ページ

![ページは特定のルートに紐づくビューです](/assets/docs/getting-started/views/pages.svg)

ページは各ルートパターンごとのビューを表します。[`pages/`](/docs/guide/directory-structure/pages) ディレクトリ内の各ファイルが異なるルートとなり、その内容が表示されます。

ページを使うには、`pages/index.vue` ファイルを作成し、[`app.vue`](/docs/guide/directory-structure/app) に `<NuxtPage />` コンポーネントを追加します（または `app.vue` を削除してデフォルトエントリにします）。その後、[`pages/`](/docs/guide/directory-structure/pages) ディレクトリに新しいファイルを追加することで、さらにページと対応するルートを作成できます。

::code-group

```vue [pages/index.vue]
<template>
  <div>
    <h1>ホームページへようこそ</h1>
    <AppAlert>
      これは自動インポートされたコンポーネントです
    </AppAlert>
  </div>
</template>
```

```vue [pages/about.vue]
<template>
  <section>
    <p>このページは /about ルートで表示されます。</p>
  </section>
</template>
```

::

## レイアウト

![レイアウトはページをラップするものです](/assets/docs/getting-started/views/layouts.svg)

レイアウトは複数ページで共通のユーザーインターフェース（ヘッダーやフッターなど）を含むページのラッパーです。レイアウトは `<slot />` コンポーネントを使って**ページ**の内容を表示する Vue ファイルです。`layouts/default.vue` ファイルがデフォルトで使われます。カスタムレイアウトはページのメタデータで指定できます。

::note
アプリケーションにレイアウトが 1 つしかない場合は、[`app.vue`](/docs/guide/directory-structure/app) で [`<NuxtPage />`](/docs/api/components/nuxt-page) を使うことを推奨します。
::

::code-group

```vue [app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage />
    </NuxtLayout>
  </div>
</template>
```

```vue [layouts/default.vue]
<template>
  <div>
    <AppHeader />
    <slot />
    <AppFooter />
  </div>
</template>
```

```vue [pages/index.vue]
<template>
  <div>
    <h1>ホームページへようこそ</h1>
    <AppAlert>
      これは自動インポートされたコンポーネントです
    </AppAlert>
  </div>
</template>
```

```vue [pages/about.vue]
<template>
  <section>
    <p>このページは /about ルートで表示されます。</p>
  </section>
</template>
```

::

さらにレイアウトを作成したり、ページでの使い方を知りたい場合は [レイアウトセクション](/docs/guide/directory-structure/layouts) をご覧ください。

## 上級: HTML テンプレートの拡張

::note
`<head>` だけを変更したい場合は [SEO と meta セクション](/docs/getting-started/seo-meta) を参照してください。
::

Nitro プラグインを追加してフックを登録することで、HTML テンプレートを完全に制御できます。
`render:html` フックのコールバック関数で、クライアントに送信される前の HTML を変更できます。

<!-- TODO: figure out how to use twoslash to inject types for a different context -->

```ts [server/plugins/extend-html.ts]
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('render:html', (html, { event }) => {
    // これは html テンプレートのオブジェクト表現です。
    console.log(html)
    html.head.push(`<meta name="description" content="My custom description" />`)
  })
  // ここでレスポンスをインターセプトすることもできます。
  nitroApp.hooks.hook('render:response', (response, { event }) => { console.log(response) })
})
```
