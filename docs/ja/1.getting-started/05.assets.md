Nuxt では、スタイルシート・フォント・画像などのアセットを管理するために 2 つのディレクトリを使用します。

- [`public/`](/docs/guide/directory-structure/public) ディレクトリの内容はサーバールートでそのまま配信されます。
- [`assets/`](/docs/guide/directory-structure/assets) ディレクトリには、ビルドツール（Vite または webpack）で処理したいアセットを慣例的に配置します。

## Public ディレクトリ

[`public/`](/docs/guide/directory-structure/public) ディレクトリは、アプリケーションの特定の URL で公開される静的アセット用のパブリックサーバーとして使われます。

[`public/`](/docs/guide/directory-structure/public) ディレクトリ内のファイルは、アプリケーションのコードやブラウザからルート URL `/` で取得できます。

### 例:

たとえば、`public/img/` ディレクトリ内の画像ファイルは、静的 URL `/img/nuxt.png` で利用できます:

```vue [app.vue]
<template>
  <img src="/img/nuxt.png" alt="Discover Nuxt" />
</template>
```

## Assets ディレクトリ

Nuxt は [Vite](https://vite.dev/guide/assets.html)（デフォルト）または [webpack](https://webpack.js.org/guides/asset-management) を使ってアプリケーションをビルド・バンドルします。これらのビルドツールの主な役割は JavaScript ファイルの処理ですが、[プラグイン](https://vite.dev/plugins)（Vite 用）や [ローダー](https://webpack.js.org/loaders)（webpack 用）を通じて、スタイルシート・フォント・SVG など他のアセットも処理できます。このステップでファイルを変換し、主にパフォーマンスやキャッシュ目的（例: スタイルシートの最小化やキャッシュ無効化）で利用されます。

慣例として、Nuxt はこれらのファイルを [`assets/`](/docs/guide/directory-structure/assets) ディレクトリに保存しますが、このディレクトリの自動スキャン機能はなく、他の名前でも利用可能です。

アプリケーションのコード内では、[`assets/`](/docs/guide/directory-structure/assets) ディレクトリ内のファイルを `~/assets/` パスで参照できます。

### 例:

たとえば、ビルドツールがこの拡張子を処理するよう設定されていれば、画像ファイルを次のように参照できます:

```vue [app.vue]
<template>
  <img src="~/assets/img/nuxt.png" alt="Discover Nuxt" />
</template>
```

::note
Nuxt は [`assets/`](/docs/guide/directory-structure/assets) ディレクトリ内のファイルを `/assets/my-file.png` のような静的 URL で配信しません。静的 URL が必要な場合は [`public/`](#public-directory) ディレクトリを利用してください。
::
