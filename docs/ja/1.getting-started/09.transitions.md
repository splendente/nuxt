::note
Nuxt は Vue の [`<Transition>`](https://vuejs.org/guide/built-ins/transition.html#the-transition-component) コンポーネントを活用してページとレイアウト間のトランジションを適用します。
::

## ページトランジション

ページトランジションを有効にして、すべての [ページ](/docs/guide/directory-structure/pages) に自動トランジションを適用できます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: { name: 'page', mode: 'out-in' }
  },
})
```

::note
ページと同時にレイアウトも変更している場合、ここで設定したページトランジションは実行されません。代わりに [レイアウトトランジション](/docs/getting-started/transitions#layout-transitions) を設定する必要があります。
::

ページ間のトランジションを追加するには、[`app.vue`](/docs/guide/directory-structure/app) に次の CSS を追加します:

::code-group

```vue [app.vue]
<template>
  <NuxtPage />
</template>

<style>
.page-enter-active,
.page-leave-active {
  transition: all 0.4s;
}
.page-enter-from,
.page-leave-to {
  opacity: 0;
  filter: blur(1rem);
}
</style>
```

```vue [pages/index.vue]
<template>
  <div>
    <h1>ホームページ</h1>
    <NuxtLink to="/about">アバウトページ</NuxtLink>
  </div>
</template>
```

```vue [pages/about.vue]
<template>
  <div>
    <h1>About page</h1>
    <NuxtLink to="/">Home page</NuxtLink>
  </div>
</template>
```

::

ページに異なるトランジションを設定するには、そのページの [`definePageMeta`](/docs/api/utils/define-page-meta) で `pageTransition` キーを設定します:

::code-group

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'rotate'
  }
})
</script>
```

```vue [app.vue]
<template>
  <NuxtPage />
</template>

<style>
/* ... */
.rotate-enter-active,
.rotate-leave-active {
  transition: all 0.4s;
}
.rotate-enter-from,
.rotate-leave-to {
  opacity: 0;
  transform: rotate3d(1, 1, 1, 15deg);
}
</style>
```

## レイアウトトランジション

レイアウトトランジションを有効にして、すべての [レイアウト](/docs/guide/directory-structure/layouts) に自動トランジションを適用できます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    layoutTransition: { name: 'layout', mode: 'out-in' }
  },
})
```

ページとレイアウト間のトランジションを追加するには、[`app.vue`](/docs/guide/directory-structure/app) に次の CSS を追加します:

::code-group

```vue [app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>

<style>
.layout-enter-active,
.layout-leave-active {
  transition: all 0.4s;
}
.layout-enter-from,
.layout-leave-to {
  filter: grayscale(1);
}
</style>
```

```vue [layouts/default.vue]
<template>
  <div>
    <pre>デフォルトレイアウト</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: lightgreen;
}
</style>
```

```vue [layouts/orange.vue]
<template>
  <div>
    <pre>オレンジレイアウト</pre>
    <slot />
  </div>
</template>

<style scoped>
div {
  background-color: #eebb90;
  padding: 20px;
  height: 100vh;
}
</style>
```

```vue [pages/index.vue]
<template>
  <div>
    <h1>ホームページ</h1>
    <NuxtLink to="/about">アバウトページ</NuxtLink>
  </div>
</template>
```

```vue [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'orange'
})
</script>

<template>
  <div>
    <h1>アバウトページ</h1>
    <NuxtLink to="/">ホームページ</NuxtLink>
  </div>
</template>
```

::

`pageTransition` と同様に、`definePageMeta` を使用してページコンポーネントにカスタム `layoutTransition` を適用できます:

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'orange',
  layoutTransition: {
    name: 'slide-in'
  }
})
</script>
```

## Global Settings

`nuxt.config` を使用して、これらのデフォルトトランジション名をグローバルにカスタマイズできます。

`pageTransition` と `layoutTransition` の両方のキーは、[`TransitionProps`](https://vuejs.org/api/built-in-components.html#transition) を JSON シリアライズ可能な値として受け入れ、カスタム CSS トランジションの `name`、`mode`、その他の有効な transition-props を渡すことができます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: {
      name: 'fade',
      mode: 'out-in' // デフォルト
    },
    layoutTransition: {
      name: 'slide',
      mode: 'out-in' // デフォルト
    }
  }
})
```

::warning
`name` プロパティを変更した場合、それに応じて CSS クラス名も変更する必要があります。
::

グローバルトランジションプロパティを上書きするには、`definePageMeta` を使用して単一の Nuxt ページのページまたはレイアウトトランジションを定義し、`nuxt.config` ファイルでグローバルに定義されたページまたはレイアウトトランジションを上書きします。

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'bounce',
    mode: 'out-in' // default
  }
})
</script>
```

## トランジションを無効にする

`pageTransition` と `layoutTransition` は特定のルートで無効にできます:

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: false,
  layoutTransition: false
})
</script>
```

または `nuxt.config` でグローバルに:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    pageTransition: false,
    layoutTransition: false
  }
})
```

## JavaScript フック

高度なユースケースでは、JavaScript フックを使用して Nuxt ページの非常に動的でカスタムなトランジションを作成できます。

この方法は、[GSAP](https://gsap.com) などの JavaScript アニメーションライブラリの完璧なユースケースを提供します。

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'custom-flip',
    mode: 'out-in',
    onBeforeEnter: (el) => {
      console.log('エンター前...')
    },
    onEnter: (el, done) => {},
    onAfterEnter: (el) => {}
  }
})
</script>
```

::tip
`Transition` コンポーネントで利用可能な追加の [JavaScript フック](https://vuejs.org/guide/built-ins/transition.html#javascript-hooks) について詳しく学びましょう。
::

## 動的トランジション

条件ロジックを使用して動的トランジションを適用するには、インライン [ミドルウェア](/docs/guide/directory-structure/middleware) を活用して `to.meta.pageTransition` に異なるトランジション名を割り当てることができます。

::code-group

```vue twoslash [pages/[id\\].vue]
<script setup lang="ts">
definePageMeta({
  pageTransition: {
    name: 'slide-right',
    mode: 'out-in'
  },
  middleware (to, from) {
    if (to.meta.pageTransition && typeof to.meta.pageTransition !== 'boolean')
      to.meta.pageTransition.name = +to.params.id! > +from.params.id! ? 'slide-left' : 'slide-right'
  }
})
</script>

<template>
  <h1>#{{ $route.params.id }}</h1>
</template>

<style>
.slide-left-enter-active,
.slide-left-leave-active,
.slide-right-enter-active,
.slide-right-leave-active {
  transition: all 0.2s;
}
.slide-left-enter-from {
  opacity: 0;
  transform: translate(50px, 0);
}
.slide-left-leave-to {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-enter-from {
  opacity: 0;
  transform: translate(-50px, 0);
}
.slide-right-leave-to {
  opacity: 0;
  transform: translate(50px, 0);
}
</style>
```

```vue [layouts/default.vue]
<script setup lang="ts">
const route = useRoute()
const id = computed(() => Number(route.params.id || 1))
const prev = computed(() => '/' + (id.value - 1))
const next = computed(() => '/' + (id.value + 1))
</script>

<template>
  <div>
    <slot />
    <div v-if="$route.params.id">
      <NuxtLink :to="prev">⬅️</NuxtLink> |
      <NuxtLink :to="next">➡️</NuxtLink>
    </div>
  </div>
</template>
```

::

ページは次の ID に移動するときに `slide-left` トランジションを、前の ID に移動するときに `slide-right` トランジションを適用します:

## NuxtPage とのトランジション

`app.vue` で `<NuxtPage />` を使用する場合、`transition` prop でトランジションを設定してグローバルにトランジションを有効にできます。

```vue [app.vue]
<template>
  <div>
    <NuxtLayout>
      <NuxtPage :transition="{
        name: 'bounce',
        mode: 'out-in'
      }" />
    </NuxtLayout>
  </div>
</template>
```

::note
このページトランジションは、個別のページで `definePageMeta` で上書きすることはできないことを覚えておいてください。
::

## View Transitions API（実験的）

Nuxt は [**View Transitions API**](https://developer.chrome.com/docs/web-platform/view-transitions)（[MDN](https://developer.mozilla.org/en-US/docs/Web/API/View_Transitions_API) を参照）の実験的実装を搭載しています。これは、異なるページ上の関連しない要素間でトランジションを行う能力を（特に）持つネイティブブラウザートランジションを実装するエキサイティングな新しい方法です。

https://nuxt-view-transitions.surge.sh でデモを確認し、[StackBlitz のソース](https://stackblitz.com/edit/nuxt-view-transitions)を参照できます。

Nuxt 統合は積極的に開発中ですが、設定ファイルの `experimental.viewTransition` オプションで有効にできます:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  experimental: {
    viewTransition: true
  }
})
```

可能な値は: `false`、`true`、または `'always'` です。

`true` に設定すると、ユーザーのブラウザーが `prefers-reduced-motion: reduce` にマッチする場合、Nuxt はトランジションを適用しません（推奨）。`always` に設定すると、Nuxt は常にトランジションを適用し、ユーザーの好みを尊重するかどうかはあなた次第です。

デフォルトでは、view transitions はすべての [ページ](/docs/guide/directory-structure/pages) で有効ですが、異なるグローバルデフォルトを設定できます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    // view transitions をグローバルに無効化し、ページ単位で選択
    viewTransition: false
  },
})
```

ページの [`definePageMeta`](/docs/api/utils/define-page-meta) で `viewTransition` キーを設定することで、ページのデフォルト `viewTransition` 値を上書きできます:

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  viewTransition: false
})
</script>
```

::warning
ページ単位で view transitions を上書きすることは、`experimental.viewTransition` オプションを有効にしている場合にのみ効果があります。
::

新しい View Transitions API と同じ結果を得るために `pageTransition` や `layoutTransition`（上記参照）のような Vue トランジションも使用している場合、ユーザーのブラウザーがより新しいネイティブ Web API をサポートしている場合は Vue トランジションを _無効に_ したい場合があります。これは、以下の内容で `~/middleware/disable-vue-transitions.global.ts` を作成することで行えます:

```ts
export default defineNuxtRouteMiddleware(to => {
  if (import.meta.server || !document.startViewTransition) { return }

  // 組み込み Vue トランジションを無効化
  to.meta.pageTransition = false
  to.meta.layoutTransition = false
})
```

### 既知の問題

- ページの setup 関数内でデータ取得を実行している場合、今のところこの機能の使用を再検討することをお勧めします。（設計上、View Transitions は実行中に DOM 更新を完全に凍結します。）`<Suspense>` が解決する直前の最終瞬間に View Transition を制限することを検討していますが、暫定的にこの状況に該当する場合は、この機能を採用するかどうか慈重に検討することをお勧めします。
