## Nuxt モジュールの探索

Nuxt で本番グレードのアプリケーションを開発する際、フレームワークのコア機能だけでは不十分であることがあります。Nuxt は設定オプションやプラグインで拡張できますが、複数のプロジェクトでこれらのカスタマイゼーションを維持するのは退屈で、繰り返しで、時間がかかります。一方で、すべてのプロジェクトのニーズを最初からサポートすると、Nuxt は非常に複雑で使いにくくなってしまいます。

これが、Nuxt がコアを拡張することを可能にするモジュールシステムを提供する理由の一つです。Nuxt モジュールは、[`nuxt dev`](/docs/api/commands/dev) を使用して開発モードで Nuxt を開始するときや、[`nuxt build`](/docs/api/commands/build) で本番用にプロジェクトをビルドするときに順次実行される非同期関数です。これらはテンプレートをオーバーライドし、webpack ローダーを設定し、CSS ライブラリを追加し、その他多くの有用なタスクを実行できます。

最も素晴らしいことに、Nuxt モジュールは npm パッケージで配布できます。これにより、プロジェクト間で再利用し、コミュニティと共有することが可能になり、高品質なアドオンのエコシステムの作成に役立ちます。

## Nuxt モジュールの追加

モジュールをインストールしたら、[`nuxt.config.ts`](/docs/guide/directory-structure/nuxt-config) ファイルの `modules` プロパティの下に追加できます。モジュール開発者は通常、使用に関する追加のステップと詳細を提供しています。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  modules: [
    // パッケージ名を使用（推奨される使用方法）
    '@nuxtjs/example',

    // ローカルモジュールを読み込み
    './modules/example',

    // インラインオプションでモジュールを追加
    ['./modules/example', { token: '123' }],

    // インラインモジュール定義
    async (inlineOptions, nuxt) => { }
  ]
})
```

::warning
Nuxt モジュールは現在ビルド時間のみであり、Nuxt 2 で使用されていた `buildModules` プロパティは `modules` に置き換えられて非推奨となっています。
::
