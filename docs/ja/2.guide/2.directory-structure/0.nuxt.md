::important
このディレクトリは、開発ビルドの出力をリポジトリにプッシュすることを避けるために、[`.gitignore`](/docs/guide/directory-structure/gitignore) ファイルに追加する必要があります。
::

このディレクトリは、Nuxt がディレクトリ構造に基づいて生成するファイルについて詳しく学びたい場合に興味深いものです。

Nuxt はまた、モジュールがディスクに書き込むことなくこのディレクトリにテンプレートを追加できる仮想ファイルシステム（VFS）を提供しています。

開発モードで [Nuxt DevTools](https://devtools.nuxt.com) を開き、**Virtual Files** タブにナビゲートすることで、生成されたファイルを探索できます。

::warning
[`nuxt dev`](/docs/api/commands/dev) を実行するとディレクトリ全体が再作成されるため、内部のいかなるファイルも変更しないでください。
::
