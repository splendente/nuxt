## 使用方法

**方法 1：** 名前付きエクスポートを使用

```js [composables/useFoo.ts]
export const useFoo = () => {
  return useState('foo', () => 'bar')
}
```

**方法 2：** デフォルトエクスポートを使用

```js [composables/use-foo.ts or composables/useFoo.ts]
// 拡張子を除いたファイル名のキャメルケースとして useFoo() で利用可能になります
export default function () {
  return useState('foo', () => 'bar')
}
```

**使用方法：** `.js`、`.ts`、`.vue` ファイルで自動インポートされたコンポーザブルを使用できるようになりました

```vue [app.vue]
<script setup lang="ts">
const foo = useFoo()
</script>

<template>
  <div>
    {{ foo }}
  </div>
</template>
```

::note
Nuxt の `composables/` ディレクトリは、コードに追加のリアクティビティ機能を提供するものではありません。代わりに、コンポーザブル内のリアクティビティは ref や reactive などの Vue のコンポジション API メカニズムを使用して実現されます。リアクティブなコードは `composables/` ディレクトリの境界に限定されないことにも注意してください。アプリケーション内で必要な場所でリアクティビティ機能を自由に使用できます。
::

:read-more{to="/docs/guide/concepts/auto-imports"}

:link-example{to="/docs/examples/features/auto-imports"}

## 型

内部的に、Nuxt は型を宣言するために `.nuxt/imports.d.ts` ファイルを自動生成します。

Nuxt に型を生成させるためには、[`nuxt prepare`](/docs/api/commands/prepare)、[`nuxt dev`](/docs/api/commands/dev)、または [`nuxt build`](/docs/api/commands/build) を実行する必要があることに注意してください。

::note
開発サーバーを起動せずにコンポーザブルを作成すると、TypeScript は `Cannot find name 'useBar'.` などのエラーをスローします。
::

## 例

### ネストしたコンポーザブル

自動インポートを使用して、別のコンポーザブル内でコンポーザブルを使用できます：

```js [composables/test.ts]
export const useFoo = () => {
  const nuxtApp = useNuxtApp()
  const bar = useBar()
}
```

### プラグインインジェクションへのアクセス

コンポーザブルから[プラグインインジェクション](/docs/guide/directory-structure/plugins#providing-helpers)にアクセスできます：

```js [composables/test.ts]
export const useHello = () => {
  const nuxtApp = useNuxtApp()
  return nuxtApp.$hello
}
```

## ファイルのスキャン方法

Nuxt は [`composables/` ディレクトリ](/docs/guide/directory-structure/composables)のトップレベルのファイルのみをスキャンします。例えば：

```bash [Directory Structure]
-| composables/
---| index.ts     // スキャンされる
---| useFoo.ts    // スキャンされる
---| nested/
-----| utils.ts   // スキャンされない
```

`composables/index.ts` と `composables/useFoo.ts` のみがインポート検索対象になります。

ネストしたモジュールで自動インポートを機能させるには、それらを再エクスポートする（推奨）か、ネストしたディレクトリを含むようにスキャナーを設定できます：

**例：** `composables/index.ts` ファイルから必要なコンポーザブルを再エクスポートする：

```ts [composables/index.ts]
// このエクスポートの自動インポートを有効化
export { utils } from './nested/utils.ts'
```

**例：** `composables/` フォルダ内のネストしたディレクトリをスキャンする：

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  imports: {
    dirs: [
      // トップレベルのコンポーザブルをスキャン
      '~/composables',
      // ... または特定の名前とファイル拡張子で1レベル深くネストしたコンポーザブルをスキャン
      '~/composables/*/index.{ts,js,mjs,mts}',
      // ... または指定されたディレクトリ内のすべてのコンポーザブルをスキャン
      '~/composables/**'
    ]
  }
})
```
