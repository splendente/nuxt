## レイアウトを有効にする

レイアウトは [`app.vue`](/docs/guide/directory-structure/app) に [`<NuxtLayout>`](/docs/api/components/nuxt-layout) を追加することで有効になります：

```vue [app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

レイアウトを使用するには：
- [definePageMeta](/docs/api/utils/define-page-meta) でページに `layout` プロパティを設定する。
- `<NuxtLayout>` の `name` prop を設定する。

::note
レイアウト名はケバブケースに正規化されるため、`someLayout` は `some-layout` になります。
::

::note
レイアウトが指定されていない場合、`layouts/default.vue` が使用されます。
::

::important
アプリケーションにレイアウトが 1 つしかない場合は、代わりに [`app.vue`](/docs/guide/directory-structure/app) を使用することを推奨します。
::

::important
他のコンポーネントとは異なり、レイアウト変更間のトランジションを Nuxt が適用できるようにするため、レイアウトには単一のルート要素が必要であり、このルート要素は `<slot />` にはできません。
::

## デフォルトレイアウト

`~/layouts/default.vue` を追加：

```vue [layouts/default.vue]
<template>
  <div>
    <p>すべてのページで共有されるデフォルトレイアウトコンテンツ</p>
    <slot />
  </div>
</template>
```

レイアウトファイルでは、ページのコンテンツが `<slot />` コンポーネントに表示されます。

## 名前付きレイアウト

```bash [Directory Structure]
-| layouts/
---| default.vue
---| custom.vue
```

そして、ページで `custom` レイアウトを使用できます：

```vue twoslash [pages/about.vue]
<script setup lang="ts">
definePageMeta({
  layout: 'custom'
})
</script>
```

::read-more{to="/docs/guide/directory-structure/pages#page-metadata"}
`definePageMeta` について詳しく学ぶ。
::

[`<NuxtLayout>`](/docs/api/components/nuxt-layout) の `name` プロパティを使用して、すべてのページのデフォルトレイアウトを直接上書きできます：

```vue [app.vue]
<script setup lang="ts">
// API呼び出しやログイン状態に基づいて選択する場合があります
const layout = "custom";
</script>

<template>
  <NuxtLayout :name="layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

ネストしたディレクトリにレイアウトがある場合、レイアウトの名前は独自のパスディレクトリとファイル名に基づき、重複セグメントが削除されます。

ファイル | レイアウト名
-- | --
`~/layouts/desktop/default.vue` | `desktop-default`
`~/layouts/desktop-base/base.vue` | `desktop-base`
`~/layouts/desktop/index.vue` | `desktop`

明確さのために、レイアウトのファイル名がその名前と一致することを推奨します：

ファイル | レイアウト名
-- | --
`~/layouts/desktop/DesktopDefault.vue` | `desktop-default`
`~/layouts/desktop-base/DesktopBase.vue` | `desktop-base`
`~/layouts/desktop/Desktop.vue` | `desktop`

## レイアウトを動的に変更する

[`setPageLayout`](/docs/api/utils/set-page-layout) ヘルパーを使用してレイアウトを動的に変更することもできます：

```vue twoslash
<script setup lang="ts">
function enableCustomLayout () {
  setPageLayout('custom')
}
definePageMeta({
  layout: false,
});
</script>

<template>
  <div>
    <button @click="enableCustomLayout">レイアウトを更新</button>
  </div>
</template>
```

:link-example{to="/docs/examples/features/layouts"}

## ページ単位でレイアウトを上書きする

ページを使用している場合、`layout: false` を設定してページ内で `<NuxtLayout>` コンポーネントを使用することで完全に制御できます。

::code-group

```vue [pages/index.vue]
<script setup lang="ts">
definePageMeta({
  layout: false,
})
</script>

<template>
  <div>
    <NuxtLayout name="custom">
      <template #header> ヘッダーテンプレートコンテンツ。 </template>

      ページの残りの部分
    </NuxtLayout>
  </div>
</template>
```

```vue [layouts/custom.vue]
<template>
  <div>
    <header>
      <slot name="header">
        デフォルトヘッダーコンテンツ
      </slot>
    </header>
    <main>
      <slot />
    </main>
  </div>
</template>
```

::

::important
ページ内で `<NuxtLayout>` を使用する場合は、それがルート要素でないことを確認してください（または[レイアウト/ページトランジションを無効](/docs/getting-started/transitions#disable-transitions)にしてください）。
::
