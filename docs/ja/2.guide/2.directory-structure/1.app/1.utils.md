[`utils/` ディレクトリ](/docs/guide/directory-structure/utils)の主な目的は、Vue コンポーザブルと他の自動インポートされるユーティリティ関数の間で意味的な区別を可能にすることです。

## 使用方法

**方法 1：** 名前付きエクスポートを使用

```ts twoslash [utils/index.ts]
export const { format: formatNumber } = Intl.NumberFormat('en-GB', {
  notation: 'compact',
  maximumFractionDigits: 1
})
```

**方法 2：** デフォルトエクスポートを使用

```ts twoslash [utils/random-entry.ts or utils/randomEntry.ts]
// 拡張子を除いたファイル名のキャメルケースとして randomEntry() で利用可能になります
export default function (arr: Array<any>) {
  return arr[Math.floor(Math.random() * arr.length)]
}
```

`.js`、`.ts`、`.vue` ファイルで自動インポートされたユーティリティ関数を使用できるようになりました

```vue [app.vue]
<template>
  <p>{{ formatNumber(1234) }}</p>
</template>
```

::tip
`utils/` の自動インポートの動作とスキャンの方法は、[`composables/`](/docs/guide/directory-structure/composables) ディレクトリと同じです。
::

::important
これらのユーティリティは、アプリケーションの Vue 部分でのみ利用可能です。:br
[`server/`](/docs/guide/directory-structure/server#server-utilities) ディレクトリでは `server/utils` のみが自動インポートされます。
::
