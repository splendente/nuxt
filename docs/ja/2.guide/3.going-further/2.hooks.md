::

## Nuxt フック（ビルド時）

これらのフックは [Nuxt モジュール](/docs/guide/going-further/modules)とビルドコンテキストで利用できます。

### `nuxt.config.ts` 内で

```js [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    close: () => { }
  }
})
```

### Nuxt モジュール内で

```js
import { defineNuxtModule } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    nuxt.hook('close', async () => { })
  }
})
```

::read-more{to="/docs/api/advanced/hooks#nuxt-hooks-build-time"}
利用可能なすべての Nuxt フックを探索してください。
::

## アプリフック（ランタイム）

アプリフックは主に [Nuxt プラグイン](/docs/guide/directory-structure/plugins)によってレンダリングライフサイクルにフックするために使用できますが、Vue コンポーザブルでも使用できます。

```js [plugins/test.ts]
export default defineNuxtPlugin((nuxtApp) => {
  nuxtApp.hook('page:start', () => {
    /* ここにコードを記述します */
  })
})
```

::read-more{to="/docs/api/advanced/hooks#app-hooks-runtime"}
利用可能なすべてのアプリフックを探索してください。
::

## サーバーフック（ランタイム）

これらのフックは [サーバープラグイン](/docs/guide/directory-structure/server#server-plugins)で Nitro のランタイム動作にフックするために利用できます。

```js [~/server/plugins/test.ts]
export default defineNitroPlugin((nitroApp) => {
  nitroApp.hooks.hook('render:html', (html, { event }) => {
    console.log('render:html', html)
    html.bodyAppend.push('<hr>カスタムプラグインによって追加')
  })

  nitroApp.hooks.hook('render:response', (response, { event }) => {
    console.log('render:response', response)
  })
})
```

::read-more{to="/docs/api/advanced/hooks#nitro-app-hooks-runtime-server-side"}
利用可能な Nitro ライフサイクルフックについて詳しく学んでください。
::
