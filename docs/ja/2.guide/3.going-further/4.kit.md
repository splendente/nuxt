Nuxt Kit は、[Nuxt フック](/docs/api/advanced/hooks)、[Nuxt インターフェース](/docs/guide/going-further/internals#the-nuxt-interface)との相互作用や、[Nuxt モジュール](/docs/guide/going-further/modules)の開発を非常に簡単にする Composable ユーティリティを提供します。

::read-more{to="/docs/api/kit"}
すべての Nuxt Kit ユーティリティを発見してください。
::

## 使用方法

### 依存関係のインストール

`package.json` の `dependencies` セクションに追加することで、最新の Nuxt Kit をインストールできます。ただし、Nuxt によって既にインストールされている場合でも、常に明示的に `@nuxt/kit` パッケージをインストールすることを検討してください。

::note
`@nuxt/kit` と `@nuxt/schema` は Nuxt の重要な依存関係です。別途インストールする場合は、予期しない動作を避けるために、`@nuxt/kit` と `@nuxt/schema` のバージョンが `nuxt` バージョン以上であることを確認してください。
::

```json [package.json]
{
  "dependencies": {
    "@nuxt/kit": "npm:@nuxt/kit-nightly@latest"
  }
}
```

### Kit ユーティリティのインポート

```js [test.mjs]
import { useNuxt } from '@nuxt/kit'
```

:read-more{to="/docs/api/kit"}

::note
Nuxt Kit ユーティリティはモジュールでのみ使用でき、ランタイム（コンポーネント、Vue Composables、ページ、プラグイン、サーバールート）でのインポートは想定されていません。
::

Nuxt Kit は [ESM 専用パッケージ](/docs/guide/concepts/esm)です。つまり、`require('@nuxt/kit')` を使用することは**できません**。回避策として、CommonJS コンテキストで動的インポートを使用してください：

```js [test.cjs]
// This does NOT work!
// const kit = require('@nuxt/kit')
async function main() {
  const kit = await import('@nuxt/kit')
}
main()
```
