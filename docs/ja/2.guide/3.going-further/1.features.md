---
title: "Features"
description: "Nuxt のオプション機能を有効または無効にして、新しい可能性を解き放ちます。"
---

Nuxt の一部の機能はオプトイン方式で利用でき、または必要に応じて無効にできます。

## `features`

### inlineStyles

HTML をレンダリングする際にスタイルをインライン化します。これは現在 Vite を使用している場合のみ利用可能です。

Vue コンポーネントのパスを受け取り、そのコンポーネントのスタイルをインライン化するかどうかを示すブール値を返す関数を渡すこともできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  features: {
    inlineStyles: false // またはインライン化を決定する関数
  }
})
```

### noScripts

Nuxt スクリプトと JS リソースヒントのレンダリングを無効にします。`routeRules` 内で詳細に設定することもできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  features: {
    noScripts: true
  }
})
```

## `future`

フレームワークの将来の（おそらくメジャー）バージョンでデフォルトになる新機能に早期にオプトインするための `future` 名前空間もあります。

### compatibilityVersion

::important
この設定オプションは Nuxt v3.12+ で利用可能です。現在のところ、Nuxt 4 の動作にオプトインする各レイヤーで互換性バージョンを定義する必要があることに注意してください。これは Nuxt 4 がリリースされた後は不要になります。
::

これにより、Nuxt 機能やフラグへの早期アクセスが可能になります。

`compatibilityVersion` を `4` に設定すると、
Nuxt 設定全体のデフォルトが変更されて Nuxt v4 の動作にオプトインしますが、
テスト時に Nuxt v3 の動作を詳細に再有効化することができます（例を参照）。
問題がある場合は、Nuxt またはエコシステムで対処できるよう、課題を報告してください。

```ts
export default defineNuxtConfig({
  future: {
    compatibilityVersion: 4,
  },
  // _すべての_ Nuxt v3 の動作を再有効化するには、以下のオプションを設定します：
  srcDir: '.',
  dir: {
    app: 'app'
  },
  experimental: {
    scanPageMeta: 'after-resolve',
    sharedPrerenderData: false,
    compileTemplate: true,
    resetAsyncDataToUndefined: true,
    templateUtils: true,
    relativeWatchPaths: true,
    normalizeComponentNames: false
    defaults: {
      useAsyncData: {
        deep: true
      }
    }
  },
  features: {
    inlineStyles: true
  },
  unhead: {
    renderSSRHeadOptions: {
      omitLineBreaks: false
    }
  }
})
```

### typescriptBundlerResolution

これにより TypeScript の 'Bundler' モジュール解決モードが有効になります。
これは Nuxt や [Vite](https://vite.dev/guide/performance.html#reduce-resolve-operations) などのフレームワークで推奨される設定です。

`exports` を使用する最新のライブラリを使用する際の型サポートが向上します。

[元の TypeScript プルリクエスト](https://github.com/microsoft/TypeScript/pull/51669)を参照してください。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  future: {
    typescriptBundlerResolution: true
  }
})
```
