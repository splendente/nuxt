## ランタイム設定の更新

Nuxt 3 は Nuxt 2 とは異なる方法でランタイム設定にアプローチし、新しい統合された `runtimeConfig` オプションを使用します。

まず、`publicRuntimeConfig` と `privateRuntimeConfig` プロパティを `runtimeConfig` という新しいプロパティに結合し、パブリック設定を `public` というキー内に置く必要があります。

```diff
// nuxt.config.js
- privateRuntimeConfig: {
-   apiKey: process.env.NUXT_API_KEY || 'super-secret-key'
- },
- publicRuntimeConfig: {
-   websiteURL: 'https://public-data.com'
- }
+ runtimeConfig: {
+   apiKey: process.env.NUXT_API_KEY || 'super-secret-key',
+   public: {
+     websiteURL: 'https://public-data.com'
+   }
+ }
```

これはまた、パブリックランタイム設定にアクセスする必要がある場合、それが `public` というプロパティの背後にあることを意味します。パブリックランタイム設定を使用する場合は、コードを更新する必要があります。

```diff
// MyWidget.vue
- <div>Website: {{ $config.websiteURL }}</div>
+ <div>ウェブサイト: {{ $config.public.websiteURL }}</div>
```
