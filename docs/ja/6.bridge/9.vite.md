---
title: Vite
description: 'Nuxt Bridge で Nuxt 2 アプリケーションに Vite を有効化します。'
---

::warning
`vite` を使用する際は、[nitro](/docs/bridge/nitro) が設定されている必要があります。
::

## モジュールの削除

- `nuxt-vite` を削除: Bridge が同じ機能を有効化します

## 設定の更新

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    vite: true,
    nitro: true
  }
})
```

## 設定

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  vite: {
    // Vite の設定
  }
})
```
