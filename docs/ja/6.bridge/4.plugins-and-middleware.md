## 新しいプラグイン形式

Nuxt 2 とは形式が少し異なる Nuxt 3 プラグイン API に移行できます。

プラグインは 1 つの引数（`nuxtApp`）だけを取るようになりました。詳細は[ドキュメント](/docs/guide/directory-structure/plugins)で確認できます。

```js [plugins/hello.ts]
export default defineNuxtPlugin(nuxtApp => {
  nuxtApp.provide('injected', () => 'my injected function')
  // `nuxtApp.$injected` で利用可能
})
```

::note
プラグイン内で新しい Nuxt Composable（[`useNuxtApp`](/docs/api/composables/use-nuxt-app) や `useRuntimeConfig` など）を使用したい場合は、それらのプラグインに `defineNuxtPlugin` ヘルパーを使用する必要があります。
::

::warning
`nuxtApp.vueApp` を通じて互換インターフェースが提供されていますが、プラグイン、ディレクティブ、mixin、コンポーネントをこの方法で登録する際は、複数回インストールされないことを保証する独自のロジックを追加しないと、メモリーリークを引き起こす可能性があるため、避けるべきです。
::

## 新しいミドルウェア形式

Nuxt 2 とは形式が少し異なる Nuxt 3 ミドルウェア API に移行できます。

ミドルウェアは 2 つの引数（`to`、`from`）だけを取るようになりました。詳細は[ドキュメント](/docs/guide/directory-structure/middleware)で確認できます。

```ts twoslash
export default defineNuxtRouteMiddleware((to) => {
  if (to.path !== '/') {
    return navigateTo('/')
  }
})
```

::important
`defineNuxtRouteMiddleware` の使用は、middleware ディレクトリ外ではサポートされていません。
::

## definePageMeta

Nuxt Bridge では [`definePageMeta`](/docs/api/utils/define-page-meta) も使用できます。

設定ファイルの `macros.pageMeta` オプションで有効にできます。

```ts [nuxt.config.ts]
import { defineNuxtConfig } from '@nuxt/bridge'

export default defineNuxtConfig({
  bridge: {
    macros: {
      pageMeta: true
    }
  }
})
```

::note
ただし、`middleware` と `layout` のみです。
::
