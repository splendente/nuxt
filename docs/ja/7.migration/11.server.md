ビルドされた Nuxt 3 アプリケーションにはランタイム Nuxt 依存関係がありません。つまり、サイトは高性能で超軽量になります。しかし、これは同時に、ランタイム Nuxt サーバーフックにフックできなくなることも意味します。

:read-more{to="/docs/guide/concepts/server-engine"}

## ステップ

1. `nuxt.config` 内の `render` キーを削除します。
2. `~/server/api` および `~/server/middleware` 内のファイルは自動的に登録されます。`serverMiddleware` 配列からこれらを削除できます。
3. `serverMiddleware` 配列内の他の項目を、インライン関数を使用するというよりも、ファイルや npm パッケージを直接指すように更新します。
