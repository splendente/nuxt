---

Nuxt 3 アプリ内で環境変数を参照したい場合は、ランタイム設定を使用する必要があります。

コンポーネント内でこれらの変数を参照する場合は、setup メソッド（または Nuxt プラグイン）で [`useRuntimeConfig`](/docs/api/composables/use-runtime-config) Composable を使用する必要があります。

アプリの `server/` 部分では、インポートなしで [`useRuntimeConfig`](/docs/api/composables/use-runtime-config) を使用できます。

:read-more{to="/docs/guide/going-further/runtime-config"}

## 移行

1. アプリで使用する環境変数を `nuxt.config` ファイルの `runtimeConfig` プロパティに追加します。
2. アプリの Vue 部分全体で `process.env` を [`useRuntimeConfig`](/docs/api/composables/use-runtime-config) に移行します。

::code-group

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  runtimeConfig: {
    // サーバーでのみ利用可能なプライベート設定
    apiSecret: '123',
    // public 内の設定はクライアントにも公開されます
    public: {
      apiBase: '/api'
    }
  },
})
```

```vue [pages/index.vue]
<script setup lang="ts">
const config = useRuntimeConfig()

// process.env の代わりに config.public.apiBase にアクセスします
console.log(config.public.apiBase)
</script>
```

```ts [server/api/hello.ts]
export default defineEventhandler((event) => {
  const config = useRuntimeConfig(event)
  // サーバーでは、config.public に加えて config.apiSecret にもアクセスできます
  console.log(config.apiSecret)
  console.log(config.public.apiBase)
})
```

```ini [.env]
# ランタイム設定値は、ランタイム時に一致する環境変数で自動的に置き換えられます
NUXT_API_SECRET=api_secret_token
NUXT_PUBLIC_API_BASE=https://nuxtjs.org
```
