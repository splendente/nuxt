---
title: Auto Imports
description: Nuxt 3 は最小限の障壁アプローチを採用し、可能な限りコンポーネントと Composable が自動インポートされます。
---

::note
移行ドキュメントの他の部分で、主要な Nuxt や Vue ユーティリティに明示的なインポートがないことに気付くでしょう。これはタイプミスではありません。Nuxt が自動的にインポートし、Nuxt の TypeScript サポートを使用する[指示](/docs/migration/configuration#typescript)に従っている場合、完全な型ヒントを取得できるはずです。
::

[自動インポートについて詳しく読む](/docs/guide/concepts/auto-imports)

## 移行

1. Nuxt 2 で `@nuxt/components` を使用していた場合は、`nuxt.config` の `components: true` を削除できます。より複雑な設定をしていた場合は、コンポーネントオプションが少し変更されていることに注意してください。詳細については[コンポーネントドキュメント](/docs/guide/directory-structure/components)を参照してください。

::tip
`.nuxt/types/components.d.ts` と `.nuxt/types/imports.d.ts` を確認することで、Nuxt がコンポーネントと Composable の自動インポートをどのように解決したかを確認できます。
::
