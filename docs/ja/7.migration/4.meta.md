---

Nuxt 3 はメタタグを管理するためのいくつかの異なる方法を提供します:
1. `nuxt.config` を通じて。
2. [`useHead`](/docs/api/composables/use-head) [Composable](/docs/getting-started/seo-meta) を通じて
3. [グローバルメタコンポーネント](/docs/getting-started/seo-meta) を通じて

`title`, `titleTemplate`, `base`, `script`, `noscript`, `style`, `meta`, `link`, `htmlAttrs`, `bodyAttrs` をカスタマイズできます。

::tip
Nuxt は現在、メタタグの管理に [`Unhead`](https://github.com/unjs/unhead) を使用していますが、実装の詳細は変更される可能性があります。
::

:read-more{to="/docs/getting-started/seo-meta"}

## 移行

1. `nuxt.config` で、`head` を `meta` に名前変更します。この共有メタ設定を代わりに `app.vue` に移動することを検討してください。（オブジェクトには重複除去のための `hid` キーがなくなったことに注意してください。）
2. `head` でコンポーネントの状態にアクセスする必要がある場合は、[`useHead`](/docs/api/composables/use-head) の使用に移行してください。組み込みのメタコンポーネントの使用も検討できます。
3. Options API を使用する必要がある場合は、`defineNuxtComponent` を使用する際に使用できる `head()` メソッドがあります。

### useHead

::code-group

```vue [Nuxt 2]
<script>
export default {
  data: () => ({
    title: 'My App',
    description: 'My App Description'
  })
  head () {
    return {
      title: this.title,
      meta: [{
        hid: 'description',
        name: 'description',
        content: this.description
      }]
    }
  }
}
</script>
```

```vue [Nuxt 3]
<script setup lang="ts">
const title = ref('My App')
const description = ref('My App Description')

// 上記の title/description を変更すると、これはリアクティブになります
useHead({
  title,
  meta: [{
    name: 'description',
    content: description
  }]
})
</script>
```

::

### メタコンポーネント

Nuxt 3 は同じタスクを実行するために使用できるメタコンポーネントも提供します。これらのコンポーネントは HTML タグに似ていますが、Nuxt によって提供され、同様の機能を持っています。

::code-group

```vue [Nuxt 2]
<script>
export default {
  head () {
    return {
      title: 'My App',
      meta: [{
        hid: 'description',
        name: 'description',
        content: 'My App Description'
      }]
    }
  }
}
</script>
```

```vue [Nuxt 3]
<template>
  <div>
    <Head>
      <Title>My App</Title>
      <Meta name="description" content="My app description"/>
    </Head>
    <!-- -->
  </div>
</template>
```

::

::important
1. ネイティブ HTML 要素と区別するために、これらのコンポーネント名は大文字を使用してください（`<title>` ではなく `<Title>`）。
2. これらのコンポーネントはページのテンプレート内のどこにでも配置できます。
::

### Options API

```vue [Nuxt 3 (Options API)]
<script>
// Options API の `head` メソッドを使用する場合は、`defineNuxtComponent` を使用する必要があります
export default defineNuxtComponent({
  head (nuxtApp) {
    // `head` は nuxt アプリを受け取りますが、コンポーネントインスタンスにはアクセスできません
    return {
      meta: [{
        name: 'description',
        content: 'This is my page description.'
      }]
    }
  }
})
</script>
```
