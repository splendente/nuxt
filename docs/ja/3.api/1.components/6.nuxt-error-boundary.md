::tip
`<NuxtErrorBoundary>` は内部で Vue の [`onErrorCaptured`](https://vuejs.org/api/composition-api-lifecycle.html#onerrorcaptured) フックを使用しています。
::

## Events

- `@error`: コンポーネントのデフォルト slot がエラーをスローしたときに発行されるイベントです。

  ```vue
  <template>
    <NuxtErrorBoundary @error="logSomeError">
      <!-- ... -->
    </NuxtErrorBoundary>
  </template>
  ```

## Slots

- `#error`: エラーの場合に表示する fallback コンテンツを指定します。

  ```vue
    <template>
      <NuxtErrorBoundary>
        <!-- ... -->
        <template #error="{ error, clearError }">
          <p>エラーが発生しました: {{ error }}</p>

          <button @click="clearError">エラーをクリア</button>
        </template>
      </NuxtErrorBoundary>
    </template>
  ```

:read-more{to="/docs/getting-started/error-handling"}

## Examples

### script 内で `error` と `clearError` にアクセスする

以下のようにコンポーネントの script 内で `error` と `clearError` プロパティーにアクセスできます:

```vue
<template>
  <NuxtErrorBoundary ref="errorBoundary">
    <!-- ... -->
  </NuxtErrorBoundary>
</template>

<script setup lang="ts">
const errorBoundary = useTemplateRef('errorBoundary')

// errorBoundary.value?.error
// errorBoundary.value?.clearError()
</script>
```
