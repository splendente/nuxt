::important
このコンポーネントは Nuxt v3.17+ で利用可能です。
::

`<NuxtTime>` コンポーネントを使用すると、適切な `<time>` HTML セマンティクスでロケールに優しい形式で日付と時間を表示できます。hydration の不一致なしにサーバーとクライアント間で一貫したレンダリングを保証します。

## Usage

アプリ内のどこでも `<NuxtTime>` コンポーネントを使用できます:

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
</template>
```

## Props

### `datetime`

- Type: `Date | number | string`
- Required: `true`

表示する日付と時刻の値。以下を提供できます:
- `Date` オブジェクト
- タイムスタンプ（数値）
- ISO 形式の日付文字列

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
  <NuxtTime :datetime="new Date()" />
  <NuxtTime datetime="2023-06-15T09:30:00.000Z" />
</template>
```

### `locale`

- Type: `string`
- Required: `false`
- Default: ブラウザーまたはサーバーのデフォルトロケールを使用

フォーマット用の [BCP 47 言語タグ](https://datatracker.ietf.org/doc/html/rfc5646)（例: 'en-US', 'fr-FR', 'ja-JP'）:

```vue
<template>
  <NuxtTime :datetime="Date.now()" locale="fr-FR" />
</template>
```

### フォーマット Props

このコンポーネントは [Intl.DateTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat/DateTimeFormat) オプションのプロパティを受け付けます:

```vue
<template>
  <NuxtTime 
    :datetime="Date.now()" 
    year="numeric"
    month="long"
    day="numeric"
    hour="2-digit"
    minute="2-digit"
  />
</template>
```

これは「April 22, 2025, 08:30 AM」のような出力になります

### `relative`

- Type: `boolean`
- Required: `false`
- Default: `false`

Intl.RelativeTimeFormat API を使用した相対時間フォーマットを有効にします:

```vue
<template>
  <!-- 「5 minutes ago」のような表示 -->
  <NuxtTime :datetime="Date.now() - 5 * 60 * 1000" relative />
</template>
```

### 相対時間フォーマット Props

`relative` が `true` に設定されている場合、コンポーネントは [Intl.RelativeTimeFormat](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/RelativeTimeFormat/RelativeTimeFormat) のプロパティも受け付けます:

```vue
<template>
  <NuxtTime 
    :datetime="Date.now() - 3 * 24 * 60 * 60 * 1000" 
    relative 
    numeric="auto"
    style="long"
  />
</template>
```

これは `numeric` の設定に応じて「3 days ago」や「last Friday」のような出力になります。

## 例

### 基本的な使用方法

```vue
<template>
  <NuxtTime :datetime="Date.now()" />
</template>
```

### カスタムフォーマット

```vue
<template>
  <NuxtTime 
    :datetime="Date.now()" 
    weekday="long"
    year="numeric"
    month="short"
    day="numeric"
    hour="numeric"
    minute="numeric"
    second="numeric"
    timeZoneName="short"
  />
</template>
```

### 相対時間

```vue
<template>
  <div>
    <p>
      <NuxtTime :datetime="Date.now() - 30 * 1000" relative />
      <!-- 30 seconds ago -->
    </p>
    <p>  
      <NuxtTime :datetime="Date.now() - 45 * 60 * 1000" relative />
      <!-- 45 minutes ago -->
    </p>
    <p>
      <NuxtTime :datetime="Date.now() + 2 * 24 * 60 * 60 * 1000" relative />
      <!-- in 2 days -->
    </p>
  </div>
</template>
```

### カスタムロケールを使用

```vue
<template>
  <div>
    <NuxtTime :datetime="Date.now()" locale="en-US" weekday="long" />
    <NuxtTime :datetime="Date.now()" locale="fr-FR" weekday="long" />
    <NuxtTime :datetime="Date.now()" locale="ja-JP" weekday="long" />
  </div>
</template>
```
