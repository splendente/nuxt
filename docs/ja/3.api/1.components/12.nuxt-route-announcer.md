::important
このコンポーネントは Nuxt v3.12+ で利用可能です。
::

## Usage

支援技術にページタイトルの変更を知らせてアクセシビリティを向上させるために、[`app.vue`](/docs/guide/directory-structure/app) または [`layouts/`](/docs/guide/directory-structure/layouts) に `<NuxtRouteAnnouncer/>` を追加します。これにより、スクリーンリーダーに依存するユーザーにナビゲーションの変更が通知されることが保証されます。

```vue [app.vue]
<template>
  <NuxtRouteAnnouncer />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

## Slots

ルートアナウンサーのデフォルト slot を通してカスタム HTML やコンポーネントを渡すことができます。

```vue
  <template>
    <NuxtRouteAnnouncer>
      <template #default="{ message }">
        <p>{{ message }} がロードされました。</p>
      </template>
    </NuxtRouteAnnouncer>
  </template>
```

## Props

- `atomic`: スクリーンリーダーが変更のみを通知するか、コンテンツ全体を通知するかを制御します。更新時に完全なコンテンツの読み上げを行う場合は true、変更のみの場合は false に設定します。（デフォルト `false`）
- `politeness`: スクリーンリーダー通知の緊急度を設定します: `off`（通知を無効）、`polite`（無音を待つ）、または `assertive`（即座に中断）。（デフォルト `polite`）

::callout
このコンポーネントはオプションです。:br
完全なカスタマイゼーションを実現するには、[そのソースコード](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-route-announcer.ts)に基づいて独自のものを実装できます。
::

::callout
[`useRouteAnnouncer` composable](/docs/api/composables/use-route-announcer) を使用して基盤となるアナウンサーインスタンスにフックし、カスタム通知メッセージを設定することができます。
::
