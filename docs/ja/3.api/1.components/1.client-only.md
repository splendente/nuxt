`<ClientOnly>` コンポーネントは、意図的にコンポーネントをクライアント側でのみレンダリングするために使用されます。

::note
デフォルト slot の内容はサーバーのビルドから tree-shaken されます。（これは、その中のコンポーネントで使用されている CSS が初期 HTML をレンダリングする際にインライン化されない可能性があることを意味します。）
::

## Props

- `placeholderTag` | `fallbackTag`: サーバー側でレンダリングされる tag を指定します。
- `placeholder` | `fallback`: サーバー側でレンダリングされる content を指定します。

```vue
<template>
  <div>
    <Sidebar />
    <!-- <Comment> コンポーネントはクライアント側でのみレンダリングされます -->
    <ClientOnly fallback-tag="span" fallback="Loading comments...">
      <Comment />
    </ClientOnly>
  </div>
</template>
```

## Slots

- `#fallback`: サーバー上でレンダリングされ、`<ClientOnly>` がブラウザにマウントされるまで表示される content を指定します。

```vue [pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- これはサーバー側で "span" 要素をレンダリングします -->
    <ClientOnly fallbackTag="span">
      <!-- このコンポーネントはクライアント側でのみレンダリングされます -->
      <Comments />
      <template #fallback>
        <!-- これはサーバー側でレンダリングされます -->
        <p>Loading comments...</p>
      </template>
    </ClientOnly>
  </div>
</template>
```

## Examples

### HTML Elements へのアクセス

`<ClientOnly>` 内のコンポーネントはマウント後にのみレンダリングされます。DOM 内のレンダリングされた要素にアクセスするには、template ref を監視できます:

```vue [pages/example.vue]
<script setup lang="ts">
const nuxtWelcomeRef = useTemplateRef('nuxtWelcomeRef')

// watch はコンポーネントが利用可能になった時にトリガーされます
watch(nuxtWelcomeRef, () => {
 console.log('<NuxtWelcome /> mounted')
}, { once: true })
</script>

<template>
  <ClientOnly>
    <NuxtWelcome ref="nuxtWelcomeRef" />
  </ClientOnly>
</template>
```
