## App Hooks (runtime)

利用可能なすべてのフックについては、[app のソースコード](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/nuxt.ts#L37)を確認してください。

Hook                   | Arguments           | Environment     | Description
-----------------------|---------------------|-----------------|-------------
`app:created`          | `vueApp`            | Server & Client | 初期の `vueApp` インスタンスが作成されたときに呼び出されます。
`app:error`            | `err`               | Server & Client | 致命的なエラーが発生したときに呼び出されます。
`app:error:cleared`    | `{ redirect? }`     | Server & Client | 致命的なエラーが発生したときに呼び出されます。
`vue:setup`            | -                   | Server & Client | Nuxt ルートのセットアップが初期化されたときに呼び出されます。このコールバックは同期的である必要があります。
`vue:error`            | `err, target, info` | Server & Client | Vue エラーがルートコンポーネントに伝播したときに呼び出されます。[詳しくはこちら](https://vuejs.org/api/composition-api-lifecycle.html#onerrorcaptured)
`app:rendered`         | `renderContext`     | Server          | SSR レンダリングが完了したときに呼び出されます。
`app:redirected`       | -                   | Server          | SSR リダイレクトの前に呼び出されます。
`app:beforeMount`      | `vueApp`            | Client          | アプリをマウントする前に呼び出されます。クライアント側のみで呼び出されます。
`app:mounted`          | `vueApp`            | Client          | Vue アプリが初期化されてブラウザにマウントされたときに呼び出されます。
`app:suspense:resolve` | `appComponent`      | Client          | [Suspense](https://vuejs.org/guide/built-ins/suspense.html#suspense) の resolved イベント時に呼び出されます。
`app:manifest:update`  | `{ id, timestamp }` | Client          | アプリの新しいバージョンが検出されたときに呼び出されます。
`app:data:refresh`     | `keys?`             | Client          | `refreshNuxtData` が呼び出されたときに呼び出されます。
`link:prefetch`        | `to`                | Client          | `<NuxtLink>` がプリフェッチされると観察されたときに呼び出されます。
`page:start`           | `pageComponent?`    | Client          | `NuxtPage` 内の [Suspense](https://vuejs.org/guide/built-ins/suspense.html#suspense) の pending イベント時に呼び出されます。
`page:finish`          | `pageComponent?`    | Client          | `NuxtPage` 内の [Suspense](https://vuejs.org/guide/built-ins/suspense.html#suspense) の resolved イベント時に呼び出されます。
`page:loading:start`   | -                   | Client          | 新しいページの `setup()` が実行されているときに呼び出されます。
`page:loading:end`     | -                   | Client          | `page:finish` の後に呼び出されます。
`page:transition:finish`| `pageComponent?`    | Client          | ページ遷移の [onAfterLeave](https://vuejs.org/guide/built-ins/transition.html#javascript-hooks) イベントの後に呼び出されます。
`dev:ssr-logs`         | `logs`              | Client          | (`features.devLogs` が有効な場合) クライアントに渡されたサーバーサイドログの配列と共に呼び出されます。
`page:view-transition:start` | `transition`        | Client          | [実験的な viewTransition サポートが有効](/docs/getting-started/transitions#view-transitions-api-experimental)な場合に `document.startViewTransition` が呼び出された後に呼び出されます。

## Nuxt Hooks (build time)

利用可能なすべてのフックについては、[schema のソースコード](https://github.com/nuxt/nuxt/blob/main/packages/schema/src/types/hooks.ts#L83)を確認してください。

Hook                     | Arguments                  | Description
-------------------------|----------------------------|-------------
`kit:compatibility`      | `compatibility, issues`    | 互換性チェックの拡張を可能にします。
`ready`                  | `nuxt`                     | Nuxt の初期化後、Nuxt インスタンスが動作可能になったときに呼び出されます。
`close`                  | `nuxt`                     | Nuxt インスタンスが正常に終了するときに呼び出されます。
`restart`                | `{ hard?: boolean }`       | 現在の Nuxt インスタンスを再起動するために呼び出されます。
`modules:before`         | -                          | Nuxt の初期化中、ユーザーモジュールをインストールする前に呼び出されます。
`modules:done`           | -                          | Nuxt の初期化中、ユーザーモジュールをインストールした後に呼び出されます。
`app:resolve`            | `app`                      | `app` インスタンスを解決した後に呼び出されます。
`app:templates`          | `app`                      | `NuxtApp` の生成中に呼び出され、ビルドディレクトリに新しいファイルをカスタマイズ、変更、追加（仮想的に、または `.nuxt` に書き込み）することを可能にします。
`app:templatesGenerated` | `app`                      | テンプレートが[仮想ファイルシステム](/docs/guide/directory-structure/nuxt#virtual-file-system) (vfs) にコンパイルされた後に呼び出されます。
`build:before`           | -                          | Nuxt バンドルビルダーの前に呼び出されます。
`build:done`             | -                          | Nuxt バンドルビルダーが完了した後に呼び出されます。
`build:manifest`         | `manifest`                 | Vite と webpack によるマニフェストビルド中に呼び出されます。これにより、Nitro が最終的な HTML で `<script>` と `<link>` タグをレンダリングするために使用するマニフェストをカスタマイズできます。
`builder:generateApp`    | `options`                  | アプリを生成する前に呼び出されます。
`builder:watch`          | `event, path`              | 開発時のビルド時に、ウォッチャーがプロジェクト内のファイルまたはディレクトリの変更を検出したときに呼び出されます。
`pages:extend`           | `pages`                    | ファイルシステムからページルートがスキャンされた後に呼び出されます。
`pages:resolved`         | `pages`                    | ページルートがスキャンされたメタデータで拡張された後に呼び出されます。
`pages:routerOptions`   | `{ files: Array<{ path: string, optional?: boolean }> }` | `router.options` ファイルを解決するときに呼び出されます。配列内の後の項目は、前の項目を上書きします。
`server:devHandler`      | `handler`                  | 開発ミドルウェアが Nitro 開発サーバーに登録されるときに呼び出されます。
`imports:sources`        | `presets`                  | モジュールがソースを拡張できるように、セットアップ時に呼び出されます。
`imports:extend`         | `imports`                  | モジュールがインポートを拡張できるように、セットアップ時に呼び出されます。
`imports:context`        | `context`                  | [unimport](https://github.com/unjs/unimport) コンテキストが作成されるときに呼び出されます。
`imports:dirs`           | `dirs`                     | インポートディレクトリの拡張を可能にします。
`components:dirs`        | `dirs`                     | `app:resolve` 内で呼び出され、自動インポート可能なコンポーネントをスキャンするディレクトリを拡張できます。
`components:extend`      | `components`               | 新しいコンポーネントの拡張を可能にします。
`nitro:config`           | `nitroConfig`              | Nitro を初期化する前に呼び出され、Nitro の設定のカスタマイズを可能にします。
`nitro:init`             | `nitro`                    | Nitro が初期化された後に呼び出され、Nitro フックの登録と Nitro との直接的な相互作用を可能にします。
`nitro:build:before`     | `nitro`                    | Nitro インスタンスをビルドする前に呼び出されます。
`nitro:build:public-assets`     | `nitro`                    | パブリックアセットをコピーした後に呼び出されます。Nitro サーバーがビルドされる前にパブリックアセットを変更できます。
`prerender:routes`       | `ctx`                      | プリレンダリングするルートの拡張を可能にします。
`build:error`            | `error`                    | ビルド時にエラーが発生したときに呼び出されます。
`prepare:types`          | `options`                  | `@nuxt/cli` が TypeScript 設定ファイル（`.nuxt/tsconfig.app.json`、`.nuxt/tsconfig.server.json` など）と `.nuxt/nuxt.d.ts` を書き込む前に呼び出され、`nuxt.d.ts` にカスタム参照と宣言を追加したり、生成された設定のオプションを直接変更できます。
`listen`                 | `listenerServer, listener` | 開発サーバーが読み込まれるときに呼び出されます。
`schema:extend`          | `schemas`                  | デフォルトスキーマの拡張を可能にします。
`schema:resolved`        | `schema`                   | 解決されたスキーマの拡張を可能にします。
`schema:beforeWrite`     | `schema`                   | 指定されたスキーマを書き込む前に呼び出されます。
`schema:written`         | -                          | スキーマが書き込まれた後に呼び出されます。
`vite:extend`            | `viteBuildContext`         | Vite のデフォルトコンテキストの拡張を可能にします。
`vite:extendConfig`      | `viteInlineConfig, env`    | Vite のデフォルト設定の拡張を可能にします。
`vite:configResolved`    | `viteInlineConfig, env`    | 解決された Vite 設定の読み取りを可能にします。
`vite:serverCreated`     | `viteServer, env`          | Vite サーバーが作成されたときに呼び出されます。
`vite:compiled`          | -                          | Vite サーバーがコンパイルされた後に呼び出されます。
`webpack:config`         | `webpackConfigs`           | webpack コンパイラーを設定する前に呼び出されます。
`webpack:configResolved` | `webpackConfigs`           | 解決された webpack 設定の読み取りを可能にします。
`webpack:compile`        | `options`                  | コンパイルの直前に呼び出されます。
`webpack:compiled`       | `options`                  | リソースが読み込まれた後に呼び出されます。
`webpack:change`         | `shortPath`                | WebpackBar で `change` 時に呼び出されます。
`webpack:error`          | -                          | WebpackBar でエラーがある場合の `done` 時に呼び出されます。
`webpack:done`           | -                          | WebpackBar で `allDone` 時に呼び出されます。
`webpack:progress`       | `statesArray`              | WebpackBar で `progress` 時に呼び出されます。

## Nitro App Hooks (runtime, server-side)

利用可能なすべてのフックについては [Nitro](https://nitro.build/guide/plugins#available-hooks) を参照してください。

Hook                   | Arguments             | Description                          | Types
-----------------------|-----------------------|--------------------------------------|------------------
`dev:ssr-logs`         | `{ path, logs }`      | Server                               | サーバーサイドログの配列と共に、リクエストサイクルの最後に呼び出されます。
`render:response`      | `response, { event }` | レスポンスを送信する前に呼び出されます。  | [response](https://github.com/nuxt/nuxt/blob/71ef8bd3ff207fd51c2ca18d5a8c7140476780c7/packages/nuxt/src/core/runtime/nitro/renderer.ts#L24), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)
`render:html`          | `html, { event }`     | HTML を構築する前に呼び出されます。 | [html](https://github.com/nuxt/nuxt/blob/71ef8bd3ff207fd51c2ca18d5a8c7140476780c7/packages/nuxt/src/core/runtime/nitro/renderer.ts#L15), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)
`render:island`        | `islandResponse, { event, islandContext }` | アイランド HTML を構築する前に呼び出されます。 | [islandResponse](https://github.com/nuxt/nuxt/blob/e50cabfed1984c341af0d0c056a325a8aec26980/packages/nuxt/src/core/runtime/nitro/renderer.ts#L28), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), [islandContext](https://github.com/nuxt/nuxt/blob/e50cabfed1984c341af0d0c056a325a8aec26980/packages/nuxt/src/core/runtime/nitro/renderer.ts#L38)
`close`               | -                | Nitro が終了したときに呼び出されます。 | -
`error`               | `error, { event? }`          | エラーが発生したときに呼び出されます。 | [error](https://github.com/nitrojs/nitro/blob/d20ffcbd16fc4003b774445e1a01e698c2bb078a/src/types/runtime/nitro.ts#L48), [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)
`request`             | `event`        | リクエストが受信されたときに呼び出されます。 | [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38)
`beforeResponse`      | `event, { body }`        | レスポンスを送信する前に呼び出されます。 | [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), unknown
`afterResponse`       | `event, { body }`        | レスポンスを送信した後に呼び出されます。 | [event](https://github.com/h3js/h3/blob/f6ceb5581043dc4d8b6eab91e9be4531e0c30f8e/src/types.ts#L38), unknown
