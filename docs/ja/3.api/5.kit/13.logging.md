Nuxt は、追加機能付きでメッセージをログに記録するために使用できるロガーインスタンスを提供します。`useLogger` を使用すると、ロガーインスタンスを取得できます。

## `useLogger`

ロガーインスタンスを返します。内部で [consola](https://github.com/unjs/consola) を使用しています。

### 使用方法

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module')

    logger.info('Hello from my module!')
  },
})
```

### 型

```ts
function useLogger (tag?: string, options?: Partial<ConsolaOptions>): ConsolaInstance
```

### パラメーター

**`tag`**: すべてのログメッセージにサフィックスとして付けるタグ。タイムスタンプの近くの右側に表示されます。

**`options`**: Consola 設定オプション。

### 例

```ts twoslash
import { defineNuxtModule, useLogger } from '@nuxt/kit'

export default defineNuxtModule({
  setup (options, nuxt) {
    const logger = useLogger('my-module', { level: options.quiet ? 0 : 3 })

    logger.info('Hello from my module!')
  },
})
```
