Nuxt の中核機能の一つは、レイヤーと拡張サポートです。デフォルトの Nuxt アプリケーションを拡張して、コンポーネント、ユーティリティ、設定を再利用できます。レイヤー構造は標準的な Nuxt アプリケーションとほぼ同じであるため、作成と保守が簡単です。

## ユースケース

- `nuxt.config` と `app.config` を使用してプロジェクト間で再利用可能な設定プリセットを共有
- [`components/`](/docs/guide/directory-structure/components) ディレクトリを使用してコンポーネントライブラリを作成
- [`composables/`](/docs/guide/directory-structure/composables) と [`utils/`](/docs/guide/directory-structure/utils) ディレクトリを使用してユーティリティと composable ライブラリを作成
- Nuxt モジュールプリセットを作成
- プロジェクト間で標準セットアップを共有
- Nuxt テーマを作成
- モジュラーアーキテクチャを実装し、大規模プロジェクトでドメイン駆動設計（DDD）パターンをサポートすることでコード組織を強化。

## 使用方法

デフォルトでは、プロジェクト内の `~~/layers` ディレクトリ内のすべてのレイヤーが、プロジェクトのレイヤーとして自動的に登録されます。

::note
レイヤーの自動登録は Nuxt v3.12.0 で導入されました。
::

さらに、これらの各レイヤーの `srcDir` への名前付きレイヤーエイリアスが自動的に作成されます。たとえば、`~~/layers/test` レイヤーに `#layers/test` 経由でアクセスできるようになります。

::note
名前付きレイヤーエイリアスは Nuxt v3.16.0 で導入されました。
::

さらに、[`nuxt.config`](/docs/guide/directory-structure/nuxt-config) ファイルに [extends](/docs/api/nuxt-config#extends) プロパティを追加することでレイヤーから拡張できます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [
    '../base',                     // ローカルレイヤーから拡張
    '@my-themes/awesome',          // インストールされた npm パッケージから拡張
    'github:my-themes/awesome#v1', // git リポジトリから拡張
  ]
})
```

プライベート GitHub リポジトリから拡張する場合は、認証トークンを渡すこともできます：

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [
    // レイヤーごとの設定
    ['github:my-themes/private-awesome', { auth: process.env.GITHUB_TOKEN }]
  ]
})
```

::tip
レイヤーソースの隣のオプションで指定することで、レイヤーのエイリアスを上書きできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  extends: [
    [
      'github:my-themes/awesome',
      { 
        meta: {
          name: 'my-awesome-theme',
        },
      },
    ],
  ]
})
```

::

Nuxt はリモートレイヤーの拡張に [unjs/c12](https://c12.unjs.io) と [unjs/giget](https://giget.unjs.io) を使用します。詳細情報と利用可能なすべてのオプションについてはドキュメントを確認してください。
