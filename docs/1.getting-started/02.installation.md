## オンラインで試す

プロジェクトをセットアップせずにブラウザで Nuxt を試したい場合は、以下のオンラインサンドボックスのいずれかを利用できます:

::card-group
  :card{title="StackBlitz で開く" icon="i-simple-icons-stackblitz" to="https://nuxt.new/s/v3" target="_blank"}
  :card{title="CodeSandbox で開く" icon="i-simple-icons-codesandbox" to="https://nuxt.new/c/v3" target="_blank"}
::

または、下記の手順に従ってご自身のコンピューターで新しい Nuxt プロジェクトをセットアップしてください。

#### 前提条件

- **Node.js** - [`20.x`](https://nodejs.org/en) 以上（[アクティブ LTS リリース](https://github.com/nodejs/release#release-schedule) の利用を推奨します）
- **テキストエディター** - IDE の指定はありませんが、[Visual Studio Code](https://code.visualstudio.com/) と [公式 Vue 拡張機能](https://marketplace.visualstudio.com/items?itemName=Vue.volar)（旧 Volar）、または [WebStorm](https://www.jetbrains.com/webstorm/) など [JetBrains IDE](https://www.jetbrains.com/ides/) を推奨します。これらは Nuxt のサポートが充実しています。
- **ターミナル** - Nuxt コマンドを実行するために必要です

::note
  ::details
  :summary[最適なセットアップのための追加メモ:]
  - **Node.js**: 偶数バージョン（18, 20 など）を使用してください
  - **Nuxtr**: コミュニティ製 [Nuxtr 拡張機能](https://marketplace.visualstudio.com/items?itemName=Nuxtr.nuxtr-vscode) をインストールしてください
  - **WSL**: Windows で HMR が遅い場合は、[WSL (Windows Subsystem for Linux)](https://docs.microsoft.com/en-us/windows/wsl/install) の利用でパフォーマンス問題が解決する場合があります。
  ::
::

[Visual Studio Code](https://code.visualstudio.com) をお使いの場合は [統合ターミナル](https://code.visualstudio.com/docs/editor/integrated-terminal) を開き、以下のコマンドで新しいスタータープロジェクトを作成します:

::code-group{sync="pm"}

```bash [npm]
npm create nuxt <project-name>
```

```bash [yarn]
yarn create nuxt <project-name>
```

```bash [pnpm]
pnpm create nuxt <project-name>
```

```bash [bun]
bun create nuxt <project-name>
```

```bash [deno]
deno -A npm:create-nuxt@latest <project-name>
```

::

::tip
他のスターターやテーマは [nuxt.new](https://nuxt.new) を開いて案内に従うことで見つけることもできます。
::

Visual Studio Code でプロジェクトフォルダーを開くには:

```bash [Terminal]
code <project-name>
```

または、ターミナルで新しいプロジェクトのディレクトリに移動します:

```bash
cd <project-name>
```

## 開発サーバー

これで Nuxt アプリを開発モードで起動できるようになります:

::code-group{sync="pm"}

```bash [npm]
npm run dev -- -o
```

```bash [yarn]
yarn dev --open
```

```bash [pnpm]
pnpm dev -o
```

```bash [bun]
bun run dev -o

# 開発時に Bun ランタイムを使う場合
# bun --bun run dev -o
```

```bash [deno]
deno run dev -o
```
::

::tip{icon="i-lucide-circle-check"}
お疲れさまでした！ブラウザウィンドウが自動的に <http://localhost:3000> を開くはずです。
::
