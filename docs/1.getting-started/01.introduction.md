Nuxt は無料の[オープンソースフレームワーク](https://github.com/nuxt/nuxt)で、[Vue.js](https://vuejs.org) を使って型安全で高性能、本格的なフルスタック Web アプリケーションや Web サイトを作成するための直感的で拡張可能な方法を提供します。

私たちは、開発時にホットモジュールリプレースメントを楽しみながら、本番環境ではデフォルトでサーバーサイドレンダリングによる高性能なアプリケーションを利用できるよう、最初から `.vue` ファイルを書き始められるようにすべてを整えました。

Nuxt にはベンダーロックインがなく、アプリケーションを[**どこにでも、エッジでも**](/blog/nuxt-on-the-edge)デプロイできます。

::tip
ブラウザで Nuxt を試してみたい場合は、[オンラインサンドボックスの一つで試すことができます](/docs/getting-started/installation#play-online)。
::

## 自動化と規約

Nuxt は規約と独創的なディレクトリ構造を使用して、反復的なタスクを自動化し、開発者が機能の推進に集中できるようにします。設定ファイルで、デフォルトの動作をカスタマイズしたり上書きしたりすることも可能です。

- **ファイルベースルーティング:** [`pages/` ディレクトリ](/docs/guide/directory-structure/pages)の構造に基づいてルートを定義します。これにより、アプリケーションの整理が簡単になり、手動でのルート設定の必要性を回避できます。
- **コード分割:** Nuxt は自動的にコードを小さなチャンクに分割し、アプリケーションの初期読み込み時間を短縮するのに役立ちます。
- **すぐに使えるサーバーサイドレンダリング:** Nuxt には組み込みの SSR 機能が付属しているため、自分で別のサーバーを設定する必要がありません。
- **自動インポート:** それぞれのディレクトリに Vue composables やコンポーネントを書き、tree-shaking と最適化された JS バンドルの利点を得ながら、インポートする必要なく使用できます。
- **データ取得ユーティリティ:** Nuxt は SSR 対応のデータ取得を処理する composables とさまざまな戦略を提供します。
- **設定不要の TypeScript サポート:** 自動生成された型と `tsconfig.json` により、TypeScript を学ぶことなく型安全なコードを書けます
- **設定済みビルドツール:** 開発時のホットモジュールリプレースメント（HMR）をサポートし、ベストプラクティスが組み込まれた本番用のコードバンドルのために、デフォルトで [Vite](https://vite.dev) を使用しています。

Nuxt はこれらの処理を担当し、フロントエンドとバックエンドの両方の機能を提供するため、重要なこと、つまり **Web アプリケーションの作成**に集中できます。

## サーバーサイドレンダリング

Nuxt には、自分でサーバーを設定することなく、デフォルトでサーバーサイドレンダリング（SSR）機能が組み込まれており、Web アプリケーションに多くの利点をもたらします:

- **初期ページ読み込み時間の高速化:** Nuxt は完全にレンダリングされた HTML ページをブラウザに送信し、すぐに表示できます。これにより、特に低速なネットワークやデバイスにおいて、より高速な知覚的ページ読み込み時間とより良いユーザーエクスペリエンス（UX）を提供できます。
- **SEO の改善:** HTML コンテンツがすぐに利用可能であるため、クライアントサイドで JavaScript がコンテンツをレンダリングする必要がなく、検索エンジンは SSR ページをより適切にインデックスできます。
- **低性能デバイスでのパフォーマンス向上:** クライアントサイドでダウンロードして実行する必要がある JavaScript の量を削減し、重い JavaScript アプリケーションの処理に苦労する可能性がある低性能デバイスに有益です。
- **アクセシビリティの向上:** 初期ページ読み込み時にコンテンツがすぐに利用可能になり、スクリーンリーダーやその他の支援技術に依存するユーザーのアクセシビリティが向上します。
- **キャッシュの簡素化:** ページをサーバーサイドでキャッシュでき、コンテンツを生成してクライアントに送信するのにかかる時間を短縮することで、パフォーマンスをさらに向上させることができます。

全体的に、サーバーサイドレンダリングは、より高速で効率的なユーザーエクスペリエンスを提供し、検索エンジン最適化とアクセシビリティを向上させることができます。

Nuxt は多目的フレームワークであるため、`nuxt generate` で静的ホスティングにアプリケーション全体を静的にレンダリングしたり、`ssr: false` オプションで SSR をグローバルに無効にしたり、`routeRules` オプションを設定してハイブリッドレンダリングを活用したりする可能性を提供します。

### サーバーエンジン

Nuxt サーバーエンジン [Nitro](https://nitro.build/) は新しいフルスタック機能を解き放ちます。

開発時には、サーバーコードとコンテキスト分離のために Rollup と Node.js workers を使用します。また、`server/api/` のファイルを読み取ることでサーバー API を生成し、`server/middleware/` からサーバーミドルウェアを生成します。

本番環境では、Nitro はアプリとサーバーを一つのユニバーサル `.output` ディレクトリにビルドします。この出力は軽量で、最小化され、Node.js モジュール（ポリフィルを除く）から削除されています。この出力は、Node.js、Serverless、Workers、Edge-side レンダリング、または純粋に静的な環境など、JavaScript をサポートする任意のシステムにデプロイできます。

:read-more{title="Nuxt サーバーエンジン" to="/docs/guide/concepts/server-engine"}

### 本番対応

Nuxt アプリケーションは、Node や Deno サーバーにデプロイしたり、静的環境でホストするために事前レンダリングしたり、サーバーレスやエッジプロバイダーにデプロイしたりできます。

### アーキテクチャ

Nuxt はさまざまな[コアパッケージ](https://github.com/nuxt/nuxt/tree/main/packages)で構成されています:

- Core engine: [nuxt](https://github.com/nuxt/nuxt/tree/main/packages/nuxt)
- Bundlers: [@nuxt/vite-builder](https://github.com/nuxt/nuxt/tree/main/packages/vite), [@nuxt/rspack-builder](https://github.com/nuxt/nuxt/tree/main/packages/rspack) and [@nuxt/webpack-builder](https://github.com/nuxt/nuxt/tree/main/packages/webpack)
- Command line interface: [@nuxt/cli](https://github.com/nuxt/cli)
- Server engine: [nitro](https://github.com/nitrojs/nitro)
- Development kit: [@nuxt/kit](https://github.com/nuxt/nuxt/tree/main/packages/kit)

Nuxt の機能と各パッケージの範囲を完全に理解するために、各コンセプトを読むことをお勧めします。
