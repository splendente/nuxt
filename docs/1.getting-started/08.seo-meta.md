Nuxt の head タグ管理は [Unhead](https://unhead.unjs.io) によって提供されています。
これは適切なデフォルト、いくつかの強力なコンポーザブル、およびアプリの head と SEO メタタグを管理するための数多くの設定オプションを提供します。

## Nuxt 設定

[`nuxt.config.ts`](/docs/guide/directory-structure/nuxt-config) で [`app.head`](/docs/api/nuxt-config#head) プロパティを提供することで、アプリ全体の head を静的にカスタマイズできます。

::important
この方法ではリアクティブデータを提供することはできません。`app.vue` で `useHead()` を使用することをお勧めします。
::

サイトタイトルのデフォルト、言語、favicon など、変更されないタグをここで設定するのが良い習慣です。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      title: 'Nuxt', // デフォルトフォールバックタイトル
      htmlAttrs: {
        lang: 'en',
      },
      link: [
        { rel: 'icon', type: 'image/x-icon', href: '/favicon.ico' },
      ]
    }
  }
})
```

以下の [Types](#types) にリストされた任意のキーを提供することもできます。

### デフォルトタグ

ウェブサイトが箱から出してうまく動作するように、いくつかのタグが Nuxt によってデフォルトで提供されています。

- `viewport`: `width=device-width, initial-scale=1`
- `charset`: `utf-8`

ほとんどのサイトではこれらのデフォルトを上書きする必要はありませんが、キー付きショートカットを使用して更新できます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      // Nuxt デフォルトを更新
      charset: 'utf-16',
      viewport: 'width=device-width, initial-scale=1, maximum-scale=1',
    }
  }
})
```

## `useHead`

[`useHead`](/docs/api/composables/use-head) コンポーザブル関数はリアクティブ入力をサポートし、head タグをプログラム的に管理できます。

```vue twoslash [app.vue]
<script setup lang="ts">
useHead({
  title: 'My App',
  meta: [
    { name: 'description', content: '私の素晴らしいサイト。' }
  ],
  bodyAttrs: {
    class: 'test'
  },
  script: [ { innerHTML: 'console.log(\'Hello world\')' } ]
})
</script>
```

[`useHead`](/docs/api/composables/use-head) と [`useHeadSafe`](/docs/api/composables/use-head-safe) コンポーザブルを確認することをお勧めします。

## `useSeoMeta`

[`useSeoMeta`](/docs/api/composables/use-seo-meta) コンポーザブルでは、サイトの SEO メタタグを完全な型安全性を持つオブジェクトとして定義できます。

これにより、`property` の代わりに `name` を使用するなどのタイプミスやよくある間違いを防ぐことができます。

```vue twoslash [app.vue]
<script setup lang="ts">
useSeoMeta({
  title: '私の素晴らしいサイト',
  ogTitle: '私の素晴らしいサイト',
  description: 'これは私の素晴らしいサイトです。すべてお話ししましょう。',
  ogDescription: 'これは私の素晴らしいサイトです。すべてお話ししましょう。',
  ogImage: 'https://example.com/image.png',
  twitterCard: 'summary_large_image',
})
</script>
```

:read-more{to="/docs/api/composables/use-seo-meta"}

## コンポーネント

[`useHead`](/docs/api/composables/use-head) の使用がすべての場合において推奨されますが、コンポーネントを使用してテンプレートで head タグを定義することを好む場合があります。

Nuxt はこの目的のために次のコンポーネントを提供しています: `<Title>`、`<Base>`、`<NoScript>`、`<Style>`、`<Meta>`、`<Link>`、`<Body>`、`<Html>`、`<Head>`。
無効なネイティブ HTML タグを使用しないように、これらのコンポーネントの大文字化に注意してください。

`<Head>` と `<Body>` は（美的理由で）ネストされたメタタグを受け入れることができますが、これは最終的な HTML でネストされたメタタグがレンダリングされる _場所_ には影響しません。

<!-- @case-police-ignore html -->

```vue [app.vue]
<script setup lang="ts">
const title = ref('こんにちは世界')
</script>

<template>
  <div>
    <Head>
      <Title>{{ title }}</Title>
      <Meta name="description" :content="title" />
      <Style>
      body { background-color: green; }
      </Style>
    </Head>

    <h1>{{ title }}</h1>
  </div>
</template>
```

タグがより直感的に重複除去されるため、コンポーネントを `<Head>` または `<Html>` コンポーネントでラップすることが推奨されます。

## 型

以下は、[`useHead`](/docs/api/composables/use-head)、[`app.head`](/docs/api/nuxt-config#head)、およびコンポーネントで使用される非リアクティブ型です。

```ts
interface MetaObject {
  title?: string
  titleTemplate?: string | ((title?: string) => string)
  templateParams?: Record<string, string | Record<string, string>>
  base?: Base
  link?: Link[]
  meta?: Meta[]
  style?: Style[]
  script?: Script[]
  noscript?: Noscript[];
  htmlAttrs?: HtmlAttributes;
  bodyAttrs?: BodyAttributes;
}
```

より詳細な型については [@unhead/vue](https://github.com/unjs/unhead/blob/main/packages/vue/src/types/schema.ts) を参照してください。

## 機能

### リアクティビティ

リアクティビティは、computed 値、getter、またはリアクティブオブジェクトを提供することで、すべてのプロパティでサポートされます。

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  const description = ref('私の素晴らしいサイト。')

  useHead({
    meta: [
      { name: 'description', content: description }
    ],
  })
  </script>
  ```

  ```vue twoslash [useSeoMeta]
  <script setup lang="ts">
  const description = ref('私の素晴らしいサイト。')

  useSeoMeta({
    description
  })
  </script>
  ```

  ```vue [Components]
  <script setup lang="ts">
  const description = ref('私の素晴らしいサイト。')
  </script>

  <template>
    <div>
      <Meta name="description" :content="description" />
    </div>
  </template>
  ```

::

### タイトルテンプレート

`titleTemplate` オプションを使用して、サイトのタイトルをカスタマイズするための動的テンプレートを提供できます。たとえば、すべてのページのタイトルにサイト名を追加することができます。

`titleTemplate` は、`%s` がタイトルで置き換えられる文字列、または関数のいずれかです。

関数を使用したい場合（完全な制御のため）、これは `nuxt.config` で設定することはできません。代わりに、サイトのすべてのページに適用される `app.vue` ファイル内で設定することが推奨されます:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} - Site Title` : 'Site Title';
    }
  })
  </script>
  ```

::

これで、サイトの別のページで [`useHead`](/docs/api/composables/use-head) を使用してタイトルを `My Page` に設定すると、ブラウザータブに 'My Page - Site Title' として表示されます。また、`null` を渡して 'Site Title' をデフォルトとすることもできます。

### テンプレートパラメーター

`templateParams` を使用して、デフォルトの `%s` 以外に `titleTemplate` 内に追加のプレースホルダーを提供できます。これにより、より動的なタイトル生成が可能になります。

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    titleTemplate: (titleChunk) => {
      return titleChunk ? `${titleChunk} %separator %siteName` : '%siteName';
    },
    templateParams: {
      siteName: 'Site Title',
      separator: '-'
    }
  })
  </script>
  ```

::

### Body タグ

該当するタグで `tagPosition: 'bodyClose'` オプションを使用して、`<body>` タグの末尾に追加できます。

例:

```vue twoslash
<script setup lang="ts">
useHead({
  script: [
    {
      src: 'https://third-party-script.com',
      // 有効なオプション: 'head' | 'bodyClose' | 'bodyOpen'
      tagPosition: 'bodyClose'
    }
  ]
})
</script>
```

## 例

### `definePageMeta` と併用

[`pages/` ディレクトリ](/docs/guide/directory-structure/pages) 内で、`definePageMeta` と [`useHead`](/docs/api/composables/use-head) を組み合わせて使用し、現在のルートに基づいてメタデータを設定できます。

たとえば、まず現在のページタイトルを設定できます（これはマクロを通じてビルド時に抽出されるため、動的に設定することはできません）:

```vue twoslash [pages/some-page.vue]
<script setup lang="ts">
definePageMeta({
  title: 'あるページ'
})
</script>
```

そしてレイアウトファイルで、前に設定したルートのメタデータを使用できます:

```vue twoslash [layouts/default.vue]
<script setup lang="ts">
const route = useRoute()

useHead({
  meta: [{ property: 'og:title', content: `App Name - ${route.meta.title}` }]
})
</script>
```

:link-example{to="/docs/examples/features/meta-tags"}

:read-more{to="/docs/guide/directory-structure/pages/#page-metadata"}

### 動的タイトル

以下の例では、`titleTemplate` は `%s` プレースホルダーを含む文字列または `function` として設定され、Nuxt アプリの各ルートに対して動的にページタイトルを設定するためのより大きな柔軟性を提供します:

```vue twoslash [app.vue]
<script setup lang="ts">
useHead({
  // 文字列として
  // `%s` がタイトルで置き換えられます
  titleTemplate: '%s - Site Title',
})
</script>
```

```vue twoslash [app.vue]
<script setup lang="ts">
useHead({
  // または関数として
  titleTemplate: (productCategory) => {
    return productCategory
      ? `${productCategory} - Site Title`
      : 'Site Title'
  }
})
</script>
```

`nuxt.config` はページタイトルを設定する代替方法としても使用されます。しかし、`nuxt.config` ではページタイトルを動的にすることはできません。そのため、`app.vue` ファイルで `titleTemplate` を使用して動的タイトルを追加し、Nuxt アプリのすべてのルートに適用することが推奨されます。

### 外部 CSS

以下の例では、[`useHead`](/docs/api/composables/use-head) コンポーザブルの `link` プロパティまたは `<Link>` コンポーネントを使用して Google Fonts を有効にする方法を示しています:

::code-group

  ```vue twoslash [useHead]
  <script setup lang="ts">
  useHead({
    link: [
      {
        rel: 'preconnect',
        href: 'https://fonts.googleapis.com'
      },
      {
        rel: 'stylesheet',
        href: 'https://fonts.googleapis.com/css2?family=Roboto&display=swap',
        crossorigin: ''
      }
    ]
  })
  </script>
  ```

  ```vue [Components]
  <template>
    <div>
      <Link rel="preconnect" href="https://fonts.googleapis.com" />
      <Link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Roboto&display=swap" crossorigin="" />
    </div>
  </template>
  ```
