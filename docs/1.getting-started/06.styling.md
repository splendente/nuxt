Nuxt はスタイリングに関して非常に柔軟です。独自のスタイルを書くことも、ローカルや外部のスタイルシートを参照することもできます。
CSS プリプロセッサ、CSS フレームワーク、UI ライブラリ、Nuxt モジュールを使ってアプリケーションをスタイリングできます。

## ローカルスタイルシート

ローカルスタイルシートを書く場合は、[`assets/` ディレクトリ](/docs/guide/directory-structure/assets) に配置するのが自然です。

### コンポーネント内でのインポート

ページ・レイアウト・コンポーネント内でスタイルシートを直接インポートできます。
JavaScript の import または CSS の [`@import` 文](https://developer.mozilla.org/ja/docs/Web/CSS/@import) を使えます。

```vue [pages/index.vue]
<script>
// サーバーサイド互換のため静的インポートを推奨
import '~/assets/css/first.css'

// 注意: 動的インポートはサーバーサイド互換ではありません
import('~/assets/css/first.css')
</script>

<style>
@import url("~/assets/css/second.css");
</style>
```

::tip
スタイルシートは Nuxt により HTML にインライン化されます。
::

### CSS プロパティ

Nuxt 設定の `css` プロパティも利用できます。
スタイルシートは [`assets/` ディレクトリ](/docs/guide/directory-structure/assets) に置くのが自然です。パスを指定すれば、Nuxt が全ページに自動で適用します。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['~/assets/css/main.css']
})
```

::tip
スタイルシートは Nuxt により HTML にインライン化され、全ページでグローバルに適用されます。
::

### フォントの利用

ローカルフォントファイルは `~/public/` ディレクトリ（例: `~/public/fonts`）に配置し、スタイルシートで `url()` で参照します。

```css [assets/css/main.css]
@font-face {
  font-family: 'FarAwayGalaxy';
  src: url('/fonts/FarAwayGalaxy.woff') format('woff');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

スタイルシート・ページ・コンポーネントでフォント名を指定して参照します:

```vue
<style>
h1 {
  font-family: 'FarAwayGalaxy', sans-serif;
}
</style>
```

### NPM 配布スタイルシート

npm で配布されているスタイルシートも参照できます。例として有名な `animate.css` ライブラリを使います。

::code-group{sync="pm"}

```bash [npm]
npm install animate.css
```

```bash [yarn]
yarn add animate.css
```

```bash [pnpm]
pnpm install animate.css
```

```bash [bun]
bun install animate.css
```

::

その後、ページ・レイアウト・コンポーネントで直接参照できます:

```vue [app.vue]
<script>
import 'animate.css'
</script>

<style>
@import url("animate.css");
</style>
```

Nuxt 設定の css プロパティで文字列として指定することもできます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['animate.css']
})
```

## 外部スタイルシート

外部スタイルシートは、nuxt.config ファイルの head セクションに link 要素を追加してアプリケーションに含められます。ローカルスタイルシートも同様に追加できます。

Nuxt 設定の [`app.head`](/docs/api/nuxt-config#head) プロパティで head を操作できます:

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  app: {
    head: {
      link: [{ rel: 'stylesheet', href: 'https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css' }]
    }
  }
})
```

### スタイルシートの動的追加

useHead composable を使って、コード内で head に動的に値をセットできます。

:read-more{to="/docs/api/composables/use-head"}

```ts twoslash
useHead({
  link: [{ rel: 'stylesheet', href: 'https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css' }]
})
```

Nuxt は内部で `unhead` を利用しています。詳細は [公式ドキュメント](https://unhead.unjs.io) を参照してください。

### Nitro プラグインで head を操作

より高度な制御が必要な場合は、フックでレンダリングされた html をインターセプトし、head をプログラム的に変更できます。

`~/server/plugins/my-plugin.ts` に次のようなプラグインを作成します:

```ts [server/plugins/my-plugin.ts]
export default defineNitroPlugin((nitro) => {
  nitro.hooks.hook('render:html', (html) => {
    html.head.push('<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/animate.css/4.1.1/animate.min.css">')
  })
})
```

外部スタイルシートはレンダーブロッキングリソースです: ブラウザがページを描画する前にロード・処理される必要があります。不要に大きなスタイルは描画を遅くします。[web.dev](https://web.dev/defer-non-critical-css) も参照してください。

## プリプロセッサの利用

SCSS・Sass・Less・Stylus などのプリプロセッサを使うには、まずインストールします。

::code-group

```bash [Sass & SCSS]
npm install -D sass
```

```bash [Less]
npm install -D less
```

```bash [Stylus]
npm install -D stylus
```

::

スタイルシートは `assets` ディレクトリに書くのが自然です。
`app.vue`（またはレイアウトファイル）でプリプロセッサの構文でインポートできます。

```vue [pages/app.vue]
<style lang="scss">
@use "~/assets/scss/main.scss";
</style>
```

または Nuxt 設定の css プロパティを使うこともできます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  css: ['~/assets/scss/main.scss']
})
```

::tip
どちらの場合も、コンパイルされたスタイルシートは Nuxt により HTML にインライン化されます。
::

プリプロセスファイルにコードを注入したい場合（例: Sass の partial で色変数を使うなど）は、Vite の [preprocessorOptions](https://vite.dev/config/shared-options.html#css-preprocessoroptions) を利用できます。

`assets` ディレクトリに partial を作成:

::code-group{sync="preprocessor"}

```scss [assets/_colors.scss]
$primary: #49240F;
$secondary: #E4A79D;
```

```sass [assets/_colors.sass]
$primary: #49240F
$secondary: #E4A79D
```

::

`nuxt.config` で次のように設定:

::code-group

```ts twoslash [SCSS]
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorOptions: {
        scss: {
          additionalData: '@use "~/assets/_colors.scss" as *;'
        }
      }
    }
  }
})
```

```ts twoslash [SASS]
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorOptions: {
        sass: {
          additionalData: '@use "~/assets/_colors.sass" as *\n'
        }
      }
    }
  }
})
```

::

Nuxt はデフォルトで Vite を使います。webpack を使いたい場合は各プリプロセッサローダーの[ドキュメント](https://webpack.js.org/loaders/sass-loader)を参照してください。

### プリプロセッサワーカー（実験的）

Vite にはプリプロセッサ利用を高速化する[実験的オプション](https://vite.dev/config/shared-options.html#css-preprocessormaxworkers)があります。

`nuxt.config` で有効化できます:

```ts
export default defineNuxtConfig({
  vite: {
    css: {
      preprocessorMaxWorkers: true // CPU 数 - 1
    }
  }
})
```

::note
これは実験的オプションです。Vite ドキュメントを参照し、[フィードバック](https://github.com/vitejs/vite/discussions/15835) をお願いします。
::

## シングルファイルコンポーネント（SFC）のスタイリング

Vue と SFC の大きな魅力の一つは、スタイリングが自然に扱える点です。コンポーネントファイルの style ブロックに直接 CSS やプリプロセッサコードを書けるので、CSS-in-JS などを使わなくても素晴らしい開発体験が得られます。CSS-in-JS を使いたい場合は [pinceau](https://github.com/Tahul/pinceau) などのサードパーティライブラリやモジュールも利用できます。

SFC でのスタイリングについては [Vue ドキュメント](https://vuejs.org/api/sfc-css-features.html) も参照してください。

### クラス・スタイルバインディング

Vue SFC の機能を活用し、class や style 属性でコンポーネントをスタイリングできます。

::code-group

```vue [Ref and Reactive]
<script setup lang="ts">
const isActive = ref(true)
const hasError = ref(false)
const classObject = reactive({
  active: true,
  'text-danger': false
})
</script>

<template>
  <div class="static" :class="{ active: isActive, 'text-danger': hasError }"></div>
  <div :class="classObject"></div>
</template>
```

```vue [Computed]
<script setup lang="ts">
const isActive = ref(true)
const error = ref(null)

const classObject = computed(() => ({
  active: isActive.value && !error.value,
  'text-danger': error.value && error.value.type === 'fatal'
}))
</script>

<template>
  <div :class="classObject"></div>
</template>
```

```vue [Array]
<script setup lang="ts">
const isActive = ref(true)
const errorClass = ref('text-danger')
</script>

<template>
  <div :class="[{ active: isActive }, errorClass]"></div>
</template>
```

```vue [Style]
<script setup lang="ts">
const activeColor = ref('red')
const fontSize = ref(30)
const styleObject = reactive({ color: 'red', fontSize: '13px' })
</script>

<template>
  <div :style="{ color: activeColor, fontSize: fontSize + 'px' }"></div>
  <div :style="[baseStyles, overridingStyles]"></div>
  <div :style="styleObject"></div>
</template>
```

::

詳細は [Vue ドキュメント](https://vuejs.org/guide/essentials/class-and-style.html) を参照してください。

### `v-bind` で動的スタイル

style ブロック内で v-bind 関数を使い、JavaScript 変数や式を参照できます。
バインディングは動的で、変数値が変わるとスタイルも更新されます。

```vue
<script setup lang="ts">
const color = ref("red")
</script>

<template>
  <div class="text">hello</div>
</template>

<style>
.text {
  color: v-bind(color);
}
</style>
```

### スコープ付きスタイル

scoped 属性を使うと、コンポーネント単位でスタイルを分離できます。この属性で宣言したスタイルはそのコンポーネントのみに適用されます。

```vue
<template>
  <div class="example">hi</div>
</template>

<style scoped>
.example {
  color: red;
}
</style>
```

### CSS Modules

module 属性で [CSS Modules](https://github.com/css-modules/css-modules) を利用できます。注入された `$style` 変数でアクセスします。

```vue
<template>
  <p :class="$style.red">This should be red</p>
</template>

<style module>
.red {
  color: red;
}
</style>
```

### プリプロセッサ対応

SFC の style ブロックはプリプロセッサ構文に対応しています。Vite は .scss, .sass, .less, .styl, .stylus ファイルを設定不要でサポートします。まずインストールすれば、lang 属性で SFC から直接利用できます。

::code-group

```vue [SCSS]
<style lang="scss">
  /* ここに scss を記述 */
</style>
```

```vue [Sass]
<style lang="sass">
  /* ここに sass を記述 */
</style>
```

```vue [LESS]
<style lang="less">
  /* ここに less を記述 */
</style>
```

```vue [Stylus]
<style lang="stylus">
  /* ここに stylus を記述 */
</style>
```

::

詳細は [Vite CSS ドキュメント](https://vite.dev/guide/features.html#css) や [@vitejs/plugin-vue ドキュメント](https://github.com/vitejs/vite-plugin-vue/tree/main/packages/plugin-vue) を参照してください。
webpack ユーザーは [vue loader ドキュメント](https://vue-loader.vuejs.org) を参照してください。

## PostCSS の利用

Nuxt には postcss が組み込まれています。`nuxt.config` ファイルで設定できます。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  postcss: {
    plugins: {
      'postcss-nested': {},
      'postcss-custom-media': {}
    }
  }
})
```

SFC で適切なシンタックスハイライトを得るには postcss の lang 属性を使えます。

```vue
<style lang="postcss">
  /* ここに postcss を記述 */
</style>
```

デフォルトで Nuxt には以下のプラグインがプリセットされています:

- [postcss-import](https://github.com/postcss/postcss-import): `@import` ルールの強化
- [postcss-url](https://github.com/postcss/postcss-url): `url()` 文の変換
- [autoprefixer](https://github.com/postcss/autoprefixer): ベンダープレフィックス自動付与
- [cssnano](https://cssnano.github.io/cssnano): 最小化とパージ

## レイアウトごとに複数スタイルを適用

アプリケーションの異なる部分をまったく異なるスタイルにしたい場合は、レイアウトを使い分けることができます。
レイアウトごとに異なるスタイルを適用しましょう。

```vue
<template>
  <div class="default-layout">
    <h1>Default Layout</h1>
    <slot />
  </div>
</template>

<style>
.default-layout {
  color: red;
}
</style>
```

:read-more{to="/docs/guide/directory-structure/layouts"}

## サードパーティライブラリ・モジュール

Nuxt はスタイリングに関して意見を持たず、さまざまな選択肢を提供します。お好きなスタイリングツールを使えます。例: [UnoCSS](https://unocss.dev) や [Tailwind CSS](https://tailwindcss.com) など。

コミュニティや Nuxt チームが多くの Nuxt モジュールを開発しており、統合が簡単です。
[公式モジュールセクション](/modules) で探せます。導入の参考になるモジュール例:

- [UnoCSS](/modules/unocss): インスタントなオンデマンド原子 CSS エンジン
- [Tailwind CSS](/modules/tailwindcss): ユーティリティファースト CSS フレームワーク
- [Fontaine](https://github.com/nuxt-modules/fontaine): フォントメトリックフォールバック
- [Pinceau](https://github.com/Tahul/pinceau): 柔軟なスタイリングフレームワーク
- [Nuxt UI](https://ui.nuxt.com): モダン Web アプリ向け UI ライブラリ
- [Panda CSS](https://panda-css.com/docs/installation/nuxt): ビルド時に原子 CSS を生成する CSS-in-JS エンジン

Nuxt モジュールはすぐに良い開発体験を提供しますが、お気に入りのツールにモジュールがなくても Nuxt で使えないわけではありません！自分で設定できます。ツールによっては [Nuxt プラグイン](/docs/guide/directory-structure/plugins) や [独自モジュール](/docs/guide/going-further/modules) の作成が必要な場合もあります。作成したら [コミュニティ](/modules) で共有しましょう！

### Web フォントの簡単ロード

[Nuxt Google Fonts モジュール](https://github.com/nuxt-modules/google-fonts) で Google Fonts を読み込めます。

[UnoCSS](https://unocss.dev/integrations/nuxt) を使う場合は、[web fonts presets](https://unocss.dev/presets/web-fonts) で Google Fonts など主要プロバイダーからフォントを簡単に読み込めます。

### LCP 高度最適化

グローバル CSS ファイルのダウンロードを高速化するには:

- CDN を使い、ファイルをユーザーの近くに配置する
- アセットを圧縮する（理想は Brotli）
- 配信に HTTP2/HTTP3 を使う
- アセットを同一ドメインでホストする（サブドメインは避ける）

これらは Cloudflare・Netlify・Vercel などのモダンプラットフォームなら自動で行われます。
LCP 最適化ガイドは [web.dev](https://web.dev/optimize-lcp) を参照してください。

すべての CSS が Nuxt によりインライン化されている場合、実験的にレンダリング HTML で外部 CSS ファイルの参照を完全に停止できます。
モジュールや Nuxt 設定ファイルで次のようなフックを使います。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  hooks: {
    'build:manifest': (manifest) => {
      // app エントリの css リストを取得
      const css = Object.values(manifest).find(options => options.isEntry)?.css
      if (css) {
        // 配列の末尾から先頭へ
        for (let i = css.length - 1; i >= 0; i--) {
          // 'entry' で始まる場合はリストから削除
          if (css[i].startsWith('entry')) css.splice(i, 1)
        }
      }
    },
  },
})
```
