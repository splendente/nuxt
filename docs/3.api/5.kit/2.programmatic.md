プログラマティック使用は、[CLI ツール](https://github.com/nuxt/cli)や[テストユーティリティ](https://github.com/nuxt/nuxt/tree/main/packages/test-utils)を構築するときなど、Nuxt をプログラマティックに使用したい場合に役立ちます。

## `loadNuxt`

Nuxt をプログラマティックに読み込みます。Nuxt 設定を読み込み、インスタンス化し、Nuxt インスタンスとともに Promise を返します。

### 型

```ts
function loadNuxt (loadOptions?: LoadNuxtOptions): Promise<Nuxt>
```

### パラメーター

**`loadOptions`**: Nuxt の読み込み条件。`loadNuxt` は内部で [`c12`](https://github.com/unjs/c12) を使用するため、`c12.loadConfig` と同じオプションに加えて、いくつかの追加オプションを受け付けます:

| プロパティ | 型      | 必須 | 説明                                                                                                                                                       |
| -------- | --------- | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dev`    | `boolean` | `false`  | `true` に設定すると、Nuxt は開発モードで読み込まれます。                                                                                                        |
| `ready`  | `boolean` | `true`   | `true` に設定すると、`loadNuxt` 呼び出し後に Nuxt は使用準備完了になります。`false` に設定すると、Nuxt が使用準備完了であることを確認するために `nuxt.ready()` を呼び出す必要があります。 |

## `buildNuxt`

Nuxt をプログラマティックにビルドします。ビルダー（現在は [@nuxt/vite-builder](https://github.com/nuxt/nuxt/tree/main/packages/vite) または [@nuxt/webpack-builder](https://github.com/nuxt/nuxt/tree/main/packages/webpack)）を呼び出してアプリケーションをバンドルします。

### 型

```ts
function buildNuxt (nuxt: Nuxt): Promise<any>
```

### パラメーター

**`nuxt`**: ビルドする Nuxt インスタンス。`useNuxt()` 呼び出しを介してコンテキストから取得できます。

## `loadNuxtConfig`

Nuxt 設定を読み込みます。設定オブジェクトとともに Promise を返します。

### 型

```ts
function loadNuxtConfig (options: LoadNuxtConfigOptions): Promise<NuxtOptions>
```

### パラメーター

**`options`**: [`c12`](https://github.com/unjs/c12#options) の `loadConfig` 呼び出しに渡すオプション。

## `writeTypes`

`tsconfig.json` を生成し、プロジェクトの buildDir に書き込みます。

### 型

```ts
function writeTypes (nuxt?: Nuxt): void
```

### パラメーター

**`nuxt`**: ビルドする Nuxt インスタンス。`useNuxt()` 呼び出しを介してコンテキストから取得できます。
