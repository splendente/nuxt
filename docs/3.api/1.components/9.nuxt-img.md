`<NuxtImg>` はネイティブの `<img>` タグのドロップイン置換です。

- 組み込み provider を使用してローカルとリモート画像を最適化します
- `src` を provider 最適化 URL に変換します
- `width` と `height` に基づいて自動的に画像をリサイズします
- `sizes` オプションを提供するとレスポンシブサイズを生成します
- ネイティブ lazy loading やその他の `<img>` 属性をサポートします

## Setup

`<NuxtImg>` を使用するには、Nuxt Image モジュールをインストールして有効にする必要があります:

```bash [Terminal]
npx nuxt module add image
```

## Usage

`<NuxtImg>` はネイティブの `img` タグを直接出力します（周りにラッパーはありません）。`<img>` タグを使用するのと同じように使用してください:

```html
<NuxtImg src="/nuxt-icon.png" />
```

結果:

```html
<img src="/nuxt-icon.png" />
```
