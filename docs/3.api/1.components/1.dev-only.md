Nuxt は開発時のみコンポーネントをレンダリングするための `<DevOnly>` コンポーネントを提供します。

内容は production ビルドには含まれません。

```vue [pages/example.vue]
<template>
  <div>
    <Sidebar />
    <DevOnly>
      <!-- このコンポーネントは開発時のみレンダリングされます -->
      <LazyDebugBar />

      <!-- production で置き換えが必要な場合 -->
      <!-- `nuxt preview` を使ってテストすることを忘れずに -->
      <template #fallback>
        <div><!-- flex.justify-between のための空の div --></div>
      </template>
    </DevOnly>
  </div>
</template>
```

## Slots

- `#fallback`: production で置き換えが必要な場合に使用します。

```vue
<template>
  <div>
    <Sidebar />
    <DevOnly>
      <!-- このコンポーネントは開発時のみレンダリングされます -->
      <LazyDebugBar />
      <!-- `nuxt preview` を使ってテストすることを忘れずに -->
      <template #fallback>
        <div><!-- flex.justify-between のための空の div --></div>
      </template>
    </DevOnly>
  </div>
</template>
```
