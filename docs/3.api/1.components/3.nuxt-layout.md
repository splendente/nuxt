`app.vue` または `error.vue` で `default` レイアウトを有効にするために `<NuxtLayout />` コンポーネントを使用できます。

```vue [app.vue]
<template>
  <NuxtLayout>
    some page content
  </NuxtLayout>
</template>
```

:read-more{to="/docs/guide/directory-structure/layouts"}

## Props

- `name`: レンダリングするレイアウト名を指定します。文字列、reactive reference、または computed property を使用できます。[`layouts/`](/docs/guide/directory-structure/layouts) ディレクトリーの対応するレイアウトファイル名と一致する**必要があります**。
  - **type**: `string`
  - **default**: `default`

```vue [pages/index.vue]
<script setup lang="ts">
// layouts/custom.vue
const layout = 'custom'
</script>

<template>
  <NuxtLayout :name="layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

::note
レイアウト名は kebab-case に正規化されることに注意してください。レイアウトファイル名が `errorLayout.vue` の場合、`<NuxtLayout />` の `name` プロパティーとして渡すときは `error-layout` になります。
::

```vue [error.vue]
<template>
  <NuxtLayout name="error-layout">
    <NuxtPage />
  </NuxtLayout>
</template>
```

::read-more{to="/docs/guide/directory-structure/layouts"}
動的レイアウトについて詳しく読む。
::

- `fallback`: 無効なレイアウトが `name` prop に渡された場合、レイアウトはレンダリングされません。このシナリオでレンダリングされる `fallback` レイアウトを指定します。[`layouts/`](/docs/guide/directory-structure/layouts) ディレクトリーの対応するレイアウトファイル名と一致する**必要があります**。
  - **type**: `string`
  - **default**: `null`

## Additional Props

`NuxtLayout` は、レイアウトに渡す必要があるかもしれない追加の props も受け取ります。これらのカスタム props は属性としてアクセス可能になります。

```vue [pages/some-page.vue]
<template>
  <div>
    <NuxtLayout name="custom" title="I am a custom layout">
      <-- ... -->
    </NuxtLayout>
  </div>
</template>
```

上記の例では、`title` の値は custom.vue で template では `$attrs.title` を使用して、`<script setup>` では `useAttrs().title` を使用してアクセスできます。

```vue [layouts/custom.vue]
<script setup lang="ts">
const layoutCustomProps = useAttrs()

console.log(layoutCustomProps.title) // I am a custom layout
</script>
```

## Transitions

`<NuxtLayout />` は受信したコンテンツを `<slot />` を介してレンダリングし、レイアウト transition を有効にするために Vue の `<Transition />` コンポーネントでラップします。これが期待通りに動作するためには、`<NuxtLayout />` がページコンポーネントのルート要素では**ない**ことを推奨します。

::code-group

```vue [pages/index.vue]
<template>
  <div>
    <NuxtLayout name="custom">
      <template #header> Some header template content. </template>
    </NuxtLayout>
  </div>
</template>
```

```vue [layouts/custom.vue]
<template>
  <div>
    <!-- named slot -->
    <slot name="header" />
    <slot />
  </div>
</template>
```

::

:read-more{to="/docs/getting-started/transitions"}

## Layout's Ref

レイアウトコンポーネントの ref を取得するには、`ref.value.layoutRef` を通してアクセスします。

::code-group

```vue [app.vue]
<script setup lang="ts">
const layout = ref()

function logFoo () {
  layout.value.layoutRef.foo()
}
</script>

<template>
  <NuxtLayout ref="layout">
    default layout
  </NuxtLayout>
</template>
```

```vue [layouts/default.vue]
<script setup lang="ts">
const foo = () => console.log('foo')
defineExpose({
  foo
})
</script>

<template>
  <div>
    default layout
    <slot />
  </div>
</template>
```
