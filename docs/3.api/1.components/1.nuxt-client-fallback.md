Nuxt は子要素のいずれかが SSR でエラーを発生させた場合に、その内容をクライアント上でレンダリングする `<NuxtClientFallback>` コンポーネントを提供します。

::note{to="/docs/guide/going-further/experimental-features#clientfallback"}
このコンポーネントは実験的であり、使用するためには `nuxt.config` で `experimental.clientFallback` オプションを有効にする必要があります。
::

```vue [pages/example.vue]
<template>
  <div>
    <Sidebar />
    <!-- このコンポーネントはクライアント側でレンダリングされます -->
    <NuxtClientFallback fallback-tag="span">
      <Comments />
      <BrokeInSSR />
    </NuxtClientFallback>
  </div>
</template>
```

## Events

- `@ssr-error`: 子要素が SSR でエラーを発生させた時に発行されるイベントです。これはサーバー上でのみトリガーされることに注意してください。

  ```vue
  <template>
    <NuxtClientFallback @ssr-error="logSomeError">
      <!-- ... -->
    </NuxtClientFallback>
  </template>
  ```

## Props

- `placeholderTag` | `fallbackTag`: slot がサーバーでレンダリングに失敗した場合にレンダリングされる fallback tag を指定します。
  - **type**: `string`
  - **default**: `div`
- `placeholder` | `fallback`: slot がレンダリングに失敗した場合にレンダリングされる fallback content を指定します。
  - **type**: `string`
- `keepFallback`: サーバー側でレンダリングに失敗した場合に fallback content を保持します。
  - **type**: `boolean`
  - **default**: `false`

```vue
  <template>
    <!-- デフォルト slot のレンダリングに失敗した場合、サーバー側で <span>Hello world</span> をレンダリングします -->
    <NuxtClientFallback fallback-tag="span" fallback="Hello world">
      <BrokeInSsr />
    </NuxtClientFallback>
  </template>
```

## Slots

- `#fallback`: slot のレンダリングに失敗した場合にサーバー側で表示される content を指定します。

```vue
<template>
  <NuxtClientFallback>
    <!-- ... -->
    <template #fallback>
      <!-- デフォルト slot が ssr でレンダリングに失敗した場合、これがサーバー側でレンダリングされます -->
      <p>Hello world</p>
    </template>
  </NuxtClientFallback>
</template>
```
