## Usage

[`app.vue`](/docs/guide/directory-structure/app) または [`layouts/`](/docs/guide/directory-structure/layouts) に `<NuxtLoadingIndicator/>` を追加します。

```vue [app.vue]
<template>
  <NuxtLoadingIndicator />
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

:link-example{to="/docs/examples/routing/pages"}

## Slots

ローディングインジケーターのデフォルト slot を通してカスタム HTML やコンポーネントを渡すことができます。

## Props

- `color`: ローディングバーの色。明示的な色のスタイリングを無効にするには `false` に設定できます。
- `errorColor`: `error` が `true` に設定されているときのローディングバーの色。
- `height`: ローディングバーの高さ（ピクセル単位、デフォルト `3`）。
- `duration`: ローディングバーの継続時間（ミリ秒単位、デフォルト `2000`）。
- `throttle`: 表示と非表示のスロットル（ミリ秒単位、デフォルト `200`）。
- `estimatedProgress`: デフォルトでは Nuxt は 100% に近づくにつれて後退します。プログレス推定をカスタマイズするカスタム関数を提供できます。これはローディングバーの継続時間（上記）と経過時間を受け取る関数です。0 と 100 の間の値を返す必要があります。

::note
このコンポーネントはオプションです。:br
完全なカスタマイゼーションを実現するには、[そのソースコード](https://github.com/nuxt/nuxt/blob/main/packages/nuxt/src/app/components/nuxt-loading-indicator.ts)に基づいて独自のものを実装できます。
::

::note
[`useLoadingIndicator` composable](/docs/api/composables/use-loading-indicator) を使用して基盤となるインジケーターインスタンスにフックし、自分で開始/終了イベントをトリガーすることができます。
::

::tip
ローディングインジケーターの速度は、`estimatedProgress` によって制御される特定のポイントに達した後、徹々に減速します。この調整により、長いページ読み込み時間をより正確に反映し、インジケーターが早すぎる 100% 完了を表示することを防いでいます。
::
