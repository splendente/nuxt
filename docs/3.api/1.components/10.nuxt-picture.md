`<NuxtPicture>` はネイティブの `<picture>` タグのドロップイン置換です。

`<NuxtPicture>` の使用方法は [`<NuxtImg>`](/docs/api/components/nuxt-img) とほぼ同じですが、可能であれば `webp` などのモダンフォーマットで提供することもできます。

[MDN の `<picture>` タグ](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/picture)について詳しく学んでください。

## Setup

`<NuxtPicture>` を使用するには、Nuxt Image モジュールをインストールして有効にする必要があります:

```bash [Terminal]
npx nuxt module add image
```
