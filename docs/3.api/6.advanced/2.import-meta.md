## `import.meta` オブジェクト

ES モジュールでは、ES モジュールをインポートまたはコンパイルするコードから一部のメタデータを取得できます。
これは、コードにこの情報を提供するオブジェクトである `import.meta` を通じて行われます。
Nuxt ドキュメント全体で、コードが現在クライアント側で実行されているかサーバー側で実行されているかを
判断するためにこれを使用したスニペットを見ることがあります。

::read-more{to="https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/import.meta"}
`import.meta` について詳しく読む。
::

## Runtime (App) Properties

これらの値は静的に注入され、ランタイムコードの tree-shaking に使用できます。

Property | Type | Description
--- | --- | ---
`import.meta.client` | boolean | クライアント側で評価される場合は true です。
`import.meta.browser` | boolean | クライアント側で評価される場合は true です。
`import.meta.server` | boolean | サーバー側で評価される場合は true です。
`import.meta.nitro` | boolean | サーバー側で評価される場合は true です。
`import.meta.dev` | boolean | Nuxt 開発サーバーを実行している場合は true です。
`import.meta.test` | boolean | テストコンテキストで実行している場合は true です。
`import.meta.prerender` | boolean | ビルドのプリレンダリング段階でサーバー上で HTML をレンダリングしている場合は true です。

## Builder Properties

これらの値は、モジュールと `nuxt.config` の両方で利用できます。

Property | Type | Description
--- | --- | ---
`import.meta.env` | object | `process.env` と等しい値です
`import.meta.url` | string | 現在のファイルの解決可能なパスです。

## 例

### モジュール内でファイルを解決するために `import.meta.url` を使用

```ts [modules/my-module/index.ts]
import { createResolver } from 'nuxt/kit'

// 現在のファイルからの相対パスを解決
const resolver = createResolver(import.meta.url)

export default defineNuxtModule({
  meta: { name: 'myModule' },
  setup() {
    addComponent({
      name: 'MyModuleComponent',
      // '/modules/my-module/components/MyModuleComponent.vue' に解決されます
      filePath: resolver.resolve('./components/MyModuleComponent.vue')
    })
  }
})
```
