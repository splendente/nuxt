## "（...）の方法がわかりません。"

このドキュメントを読んで、可能なはずだと思いますが、どうやって行うかが明確ではありません。最善の方法は [GitHub Discussion を開く](https://github.com/nuxt/nuxt/discussions)ことです。

簡単だと思う質問をすることを恥ずかしく思わないでください - 私たちみんな経験しています！❤️

あなたが出会う人はみんな、給料をもらっているからではなく、気にかけているからヘルプしています。最も親切なことは、彼らがあなたを助けやすいようにすることです。いくつかのアイデアを紹介します：

- _直面している問題だけでなく、目標を説明してください。_ "フォーム入力がアクセシブルであることを確保する必要があり、サーバーとクライアント間で ID が一致するようにしようとしています。"
- _まずドキュメントを読んでお気に入りの検索エンジンを使ったことを確認してください。_ "'nuxt script setup' で Google 検索しましたが、コード例がどこにも見つかりませんでした。"のように伝えましょう。
- _試したことを説明してください。_ 実験した解決策の種類とその理由を人々に伝えてください。これにより、しばしば人々のアドバイスがあなたの状況により関連性の高いものになります。
- _コードを共有してください。_ エラーメッセージやスクリーンショットだけではおそらく人々はヘルプできませんが、コピー＆ペースト可能な形式でコードを共有すると状況が変わります - できれば CodeSandbox のような最小限の再現の形で。

そして最後に、ただ質問してください！[質問することの許可を求める](https://dontasktoask.com)必要も、[「こんにちは」への返信を待つ](https://www.nohello.com)必要もありません。もしそうしたら、人々は関わる前に質問全体を待っているため、返信を得られないかもしれません。

## "これはバグかもしれませんか？"

ドキュメントで説明されているように動作していません。バグかどうかわかりません。[オープンな issue](https://github.com/nuxt/nuxt/issues) や [ディスカッション](https://github.com/nuxt/nuxt/discussions)を検索しましたが、何も見つかりませんでした。（クローズされた issue がある場合は、新しいものを作成してください）

[バグの報告方法](/docs/community/reporting-bugs)をご覧いただくことをお勧めします。Nuxt はまだアクティブな開発段階にあり、すべての issue がより良いものにするのに役立ちます。

## "プロフェッショナルなヘルプが必要です"

コミュニティがあなたの期限内に必要なヘルプを提供できなかった場合、NuxtLabs は [Nuxt Experts](https://nuxt.com/enterprise/support) でプロフェッショナルサポートを提供しています。

Nuxt Expert の目標は、Vue エコシステムにサポートを提供すると同時に、オープンソースソリューションに貢献する人々にフリーランスの機会を作り、エコシステムの持続可能性を維持することです。

Nuxt エキスパートは、Vue、Nuxt、Vite の選ばれた貢献者で、プロフェッショナルサポートとコンサルティングサービスを提供しています。
