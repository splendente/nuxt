Nuxt 2 アプリを Nuxt 3 に移行する際には重大な変更がありますが、安定リリースに向けて移行がより簡単になることが期待できます。

::note
この移行ガイドは Nuxt 3 の開発に合わせて進行中です。
::

これらの重大な変更の一部には以下が含まれます:

1. Vue 2 から Vue 3 への移行。Composition API と script setup のデフォルト化を含みます。
1. webpack 4 と Babel から Vite または webpack 5 と esbuild への移行。
1. ランタイム Nuxt 依存関係から nitropack でコンパイルされたミニマルなスタンドアロンサーバーへの移行。

::tip
Nuxt 2 に留まる必要があるが、Nuxt 2 で Nuxt 3 機能の恩恵を受けたい場合は、代わりに [Bridge の使い方](/docs/bridge/overview)を確認することができます。
::
