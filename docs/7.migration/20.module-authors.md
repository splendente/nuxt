## モジュール互換性

Nuxt 3 は `@nuxt/kit` 自動ラッパーを使用して Nuxt 2 モジュールの基本的な後方互換レイヤーを持っています。しかし、モジュールを Nuxt 3 互換にするために従うステップがあり、時にはクロスバージョン互換性のために Nuxt Bridge の使用が必要になることがあります。

`@nuxt/kit` を使用して Nuxt 3 対応モジュールを作成するための[専用ガイド](/docs/guide/going-further/modules)を用意しています。現在最適な移行パスは、これに従ってモジュールを書き換えることです。このガイドの残りの部分は、完全な書き換えを避けつつもモジュールを Nuxt 3 互換にしたい場合の準備ステップを含んでいます。

::tip{icon="i-lucide-puzzle" to="/modules"}
Nuxt 3 互換モジュールを探す。
::

### プラグイン互換性

Nuxt 3 プラグインは Nuxt 2 と**完全に**後方互換ではありません。

:read-more{to="/docs/guide/directory-structure/plugins"}

### Vue 互換性

Composition API を使用するプラグインやコンポーネントは、Vue 2 または Vue 3 の排他的サポートが必要です。

[vue-demi](https://github.com/vueuse/vue-demi) を使用することで、Nuxt 2 と 3 の両方で互換性を持つべきです。

## モジュール移行

Nuxt 3 ユーザーがあなたのモジュールを追加する際、モジュールコンテナ (`this.*`) にアクセスできなくなります。そのため、コンテナ機能にアクセスするために `@nuxt/kit` のユーティリティを使用する必要があります。

### `@nuxt/bridge` でのテスト

`@nuxt/bridge` への移行は、Nuxt 3 をサポートするための最初で最も重要なステップです。

モジュールにフィクスチャや例がある場合は、その設定に `@nuxt/bridge` パッケージを追加してください（[例](/docs/bridge/overview#update-nuxtconfig)を参照）

### CommonJS から ESM への移行

Nuxt 3 は TypeScript と ECMAScript Modules をネイティブサポートします。詳細とアップグレードについては [Native ES Modules](/docs/guide/concepts/esm) を確認してください。

### プラグインのデフォルトエクスポートの確保

`export default` を持たない Nuxt プラグイン（グローバル Vue プラグインなど）をインジェクトする場合は、その末尾に `export default () => { }` を追加してください。

::code-group

```js [Before]
// ~/plugins/vuelidate.js
import Vue from 'vue'
import Vuelidate from 'vuelidate'

Vue.use(Vuelidate)
```

```js [After]
// ~/plugins/vuelidate.js
import Vue from 'vue'
import Vuelidate from 'vuelidate'

Vue.use(Vuelidate)

export default () => { }
```

::

### ランタイムモジュールの回避

Nuxt 3 では、Nuxt はビルド時のみの依存関係になりました。つまり、モジュールは Nuxt ランタイムにフックしようとしてはいけません。

モジュールは（`modules` ではなく）[`buildModules`](/docs/api/nuxt-config#runtimeconfig) にのみ追加された場合でも動作するべきです。例えば:

- Nuxt モジュール内で `process.env` を更新し、Nuxt プラグインで読み取ることを避ける。代わりに [`runtimeConfig`](/docs/api/nuxt-config#runtimeconfig) を使用してください。
- (*) プロダクションで `vue-renderer:*` のようなランタイムフックに依存することを避ける
- (*) モジュール内でインポートして `serverMiddleware` を追加することを避ける。代わりに、モジュールのコンテキストから独立するようにファイルパスを参照して追加してください

(*) `nuxt dev` 目的のみで、`if (nuxt.options.dev) { }` でガードされている場合を除きます。

::tip
Nuxt 3 モジュールについての続きは[モジュール作成者ガイド](/docs/guide/going-further/modules)で読み続けてください。
::

### TypeScript の使用（任意）

必須ではありませんが、Nuxt エコシステムのほとんどが TypeScript を使用するようにシフトしているため、移行を検討することを強く推奨します。

::tip
`.js` ファイルを `.ts` にリネームすることで移行を開始できます。TypeScript は漸進的に設計されています！
::

::tip
追加の依存関係なしで、Nuxt 2 と 3 のモジュールおよびプラグインに TypeScript 構文を使用できます。
::
