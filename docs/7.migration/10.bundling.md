デフォルトで以下のビルドツールを使用します:

- [Vite](https://vite.dev) or [webpack](https://webpack.js.org)
- [Rollup](https://rollupjs.org)
- [PostCSS](https://postcss.org)
- [esbuild](https://esbuild.github.io)

このため、カスタム babel 設定を含む、`nuxt.config` 内の以前の `build` 設定のほとんどは無視されます。

Nuxt のビルドツールのいずれかを設定する必要がある場合は、新しいトップレベルの `vite`、`webpack`、`postcss` キーを使用して `nuxt.config` で実行できます。

さらに、Nuxt は TypeScript サポートが付属しています。

:read-more{to="/docs/guide/concepts/typescript"}

## ステップ

1. 依存関係およびモジュールから `@nuxt/typescript-build` および `@nuxt/typescript-runtime` を削除します。
2. プロジェクトから未使用の babel 依存関係を削除します。
3. 明示的な core-js 依存関係を削除します。
4. `require` を `import` に移行します。
