## ESLint

Nuxt の推奨アプローチは、[`@nuxt/eslint`](https://eslint.nuxt.com/packages/module) モジュールを使用して ESLint サポートを有効にすることで、プロジェクトを認識する ESLint 設定をセットアップしてくれます。

:::callout{icon="i-lucide-lightbulb"}
このモジュールは [ESLint v9 以降のデフォルト形式](https://eslint.org/blog/2024/04/eslint-v9.0.0-released/)である[新しい ESLint フラット設定形式](https://eslint.org/docs/latest/use/configure/configuration-files-new)用に設計されています。レガシーの `.eslintrc` 設定を使用している場合は、[`@nuxt/eslint-config` で手動設定](https://eslint.nuxt.com/packages/config#legacy-config-format)する必要があります。将来に備えるためにフラット設定への移行を強く推奨します。
:::

## クイックセットアップ

```bash
npx nuxt module add eslint
```

Nuxt アプリを起動すると、プロジェクトルートに `eslint.config.mjs` ファイルが生成されます。必要に応じてカスタマイズできます。

モジュールやカスタマイゼーションについて詳しくは、[Nuxt ESLint のドキュメント](https://eslint.nuxt.com/packages/module)で学ぶことができます。
