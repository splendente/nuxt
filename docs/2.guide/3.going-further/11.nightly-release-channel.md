---
title: "Nightly リリースチャンネル"
description: "Nightly リリースチャンネルでは、リポジトリの最新コミットから直接ビルドされた Nuxt を使用できます。"
---

Nuxt は毎日コミット、改善、バグ修正を行っています。次のリリースの前に、それらを早期にテストすることを選択できます。

コミットが [nuxt/nuxt](https://github.com/nuxt/nuxt) の `main` ブランチにマージされ、**すべてのテストに合格**した後、GitHub Actions を使用して自動 npm リリースをトリガーします。

これらの 'nightly' リリースを使用して、新機能や変更をベータテストできます。

これらの 'nightly' リリースのビルドおよび公開方法と品質は、安定版と同じです。唯一の違いは、GitHub リポジトリの更新を頻繁にチェックする必要があることです。レビュープロセスや自動テストでリグレッションが発見されない可能性がわずかにあります。そのため、各リリースの前にすべてを再確認するために、内部でこのチャンネルを使用しています。

::note
nightly リリースチャンネルでのみ利用可能な機能は、ドキュメントでアラートでマークされています。
::

::warning
`latest` nightly リリースチャンネルは現在 Nuxt v4 ブランチを追跡しています。つまり、現在破壊的変更がある可能性が特に高いです &mdash; 注意してください！`"nuxt": "npm:nuxt-nightly@3x"` で 3.x ブランチの nightly リリースを選択できます。
::

## オプトイン

`package.json` 内の `nuxt` 依存関係を更新します：

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "^3.0.0"
++    "nuxt": "npm:nuxt-nightly@3x"
  }
}
```

ロックファイル（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`、`bun.lock` または `bun.lockb`）を削除して、依存関係を再インストールします。

## オプトアウト

`package.json` 内の `nuxt` 依存関係を更新します：

```diff [package.json]
{
  "devDependencies": {
--    "nuxt": "npm:nuxt-nightly@3x"
++    "nuxt": "^3.0.0"
  }
}
```

ロックファイル（`package-lock.json`、`yarn.lock`、`pnpm-lock.yaml`、`bun.lock` または `bun.lockb`）を削除して、依存関係を再インストールします。

## Nightly `@nuxt/cli` の使用

[nuxt/cli](https://github.com/nuxt/cli) の最新バージョンを試すには：

```bash [Terminal]
npx @nuxt/cli-nightly@latest [command]
```

利用可能なコマンドについて詳しく読む。
::
