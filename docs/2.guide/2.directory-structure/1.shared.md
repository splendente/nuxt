`shared/` ディレクトリは、Vue アプリと Nitro サーバーの両方で使用できるコードを共有できます。

::note
`shared/` ディレクトリは Nuxt v3.14+ で利用可能です。
::

::important
`shared/` ディレクトリ内のコードは Vue や Nitro のコードをインポートできません。
::

::warning
既存プロジェクトでの破壊的変更を防ぐため、Nuxt v3 では自動インポートがデフォルトで有効になっていません。

これらの自動インポートされるユーティリティと型を使用するには、まず [`nuxt.config.ts` で `future.compatibilityVersion: 4` を設定](/docs/getting-started/upgrade#opting-in-to-nuxt-4)する必要があります。
::

## 使用方法

**方法 1：** 名前付きエクスポート

```ts twoslash [shared/utils/capitalize.ts]
export const capitalize = (input: string) => {
  return input[0] ? input[0].toUpperCase() + input.slice(1) : ''
}
```

**方法 2：** デフォルトエクスポート

```ts twoslash [shared/utils/capitalize.ts]
export default function (input: string) {
  return input[0] ? input[0].toUpperCase() + input.slice(1) : ''
}
```

Nuxt アプリと `server/` ディレクトリで[自動インポート](/docs/guide/directory-structure/shared#auto-imports)されたユーティリティを使用できるようになりました。

```vue [app.vue]
<script setup lang="ts">
const hello = capitalize('hello')
</script>

<template>
  <div>
    {{ hello }}
  </div>
</template>
```

```ts [server/api/hello.get.ts]
export default defineEventHandler((event) => {
  return {
    hello: capitalize('hello')
  }
})
```

## ファイルのスキャン方法

`shared/utils/` と `shared/types/` ディレクトリ内のファイルのみが自動インポートされます。これらのディレクトリのサブディレクトリ内にネストされたファイルは、これらのディレクトリを `imports.dirs` と `nitro.imports.dirs` に追加しない限り、自動インポートされません。

::tip
`shared/utils` と `shared/types` の自動インポートの動作とスキャン方法は、[`composables/`](/docs/guide/directory-structure/composables) と [`utils/`](/docs/guide/directory-structure/utils) ディレクトリと同じです。
::

:read-more{to="/docs/guide/directory-structure/composables#how-files-are-scanned"}

```bash [Directory Structure]
-| shared/
---| capitalize.ts        # 自動インポートされない
---| formatters
-----| lower.ts           # 自動インポートされない
---| utils/
-----| lower.ts           # 自動インポートされる
-----| formatters
-------| upper.ts         # 自動インポートされない
---| types/
-----| bar.d.ts           # 自動インポートされる
```

`shared/` フォルダ内に作成するその他のファイルは、`#shared` エイリアス（Nuxt によって自動設定）を使用して手動でインポートする必要があります：

```ts
// shared ディレクトリ直下のファイルの場合
import capitalize from '#shared/capitalize'

// ネストされたディレクトリ内のファイルの場合
import lower from '#shared/formatters/lower'

// utils 内のフォルダにネストされたファイルの場合
import upper from '#shared/utils/formatters/upper'
```

このエイリアスは、インポートするファイルの場所に関係なく、アプリケーション全体で一貫したインポートを保証します。
