::important
このディレクトリは、ビルド出力をリポジトリにプッシュすることを避けるために、[`.gitignore`](/docs/guide/directory-structure/gitignore) ファイルに追加する必要があります。
::

このディレクトリを使用して Nuxt アプリケーションを本番環境にデプロイします。

:read-more{to="/docs/getting-started/deployment"}

::warning
[`nuxt build`](/docs/api/commands/build) を実行するとディレクトリ全体が再作成されるため、内部のいかなるファイルも変更しないでください。
::
