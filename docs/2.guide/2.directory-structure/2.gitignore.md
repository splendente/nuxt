`.gitignore` ファイルは、git が無視するべき意図的に未追跡のファイルを指定します。

:read-more{icon="i-simple-icons-git" title="git ドキュメント" to="https://git-scm.com/docs/gitignore" target="_blank"}

**少なくとも**以下のエントリを含む `.gitignore` ファイルを持つことを推奨します：

```bash [.gitignore]
# Nuxt 開発/ビルド出力
.output
.data
.nuxt
.nitro
.cache
dist

# Node 依存関係
node_modules

# ログ
logs
*.log

# その他
.DS_Store

# ローカル環境ファイル
.env
.env.*
!.env.example
```
