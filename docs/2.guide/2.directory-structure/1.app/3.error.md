アプリケーションのライフスパン中に、実行時に予期しないエラーが発生することがあります。そのような場合、`error.vue` ファイルを使用してデフォルトのエラーファイルを上書きし、エラーを適切に表示できます。

```vue [error.vue]
<script setup lang="ts">
import type { NuxtError } from '#app'

const props = defineProps({
  error: Object as () => NuxtError
})
</script>

<template>
  <div>
    <h1>{{ error.statusCode }}</h1>
    <NuxtLink to="/">ホームに戻る</NuxtLink>
  </div>
</template>
```

::note
「エラーページ」と呼ばれていますが、これはルートではないため、`~/pages` ディレクトリに配置すべきではありません。同じ理由で、このページ内で `definePageMeta` を使用すべきではありません。ただし、[`NuxtLayout`](/docs/api/components/nuxt-layout) コンポーネントを使用してレイアウトの名前を指定することで、エラーファイル内でレイアウトを使用することは可能です。
::

エラーページには単一の prop `error` があり、これには処理すべきエラーが含まれています。

`error` オブジェクトは以下のフィールドを提供します：
```ts
{
  statusCode: number
  fatal: boolean
  unhandled: boolean
  statusMessage?: string
  data?: unknown
  cause?: unknown
}
```

カスタムフィールドを持つエラーがある場合、それらは失われます。代わりに `data` に割り当てる必要があります：

```ts
throw createError({
  statusCode: 404,
  statusMessage: 'ページが見つかりません',
  data: {
    myCustomField: true
  }
})
```
