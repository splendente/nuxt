::tip
`pages/` ディレクトリがある場合、`app.vue` ファイルは任意です。Nuxt は自動的にデフォルトの `app.vue` を含めますが、必要に応じて構造とコンテンツをカスタマイズするために独自のものを追加することもできます。
::

## 使用方法

### 最小限の使用方法

Nuxt では、[`pages/`](/docs/guide/directory-structure/pages) ディレクトリは任意です。存在しない場合、Nuxt は [vue-router](https://router.vuejs.org) の依存関係を含めません。これは、ランディングページやルーティングを必要としないアプリケーションを構築する際に便利です。

```vue [app.vue]
<template>
  <h1>Hello World!</h1>
</template>
```

:link-example{to="/docs/examples/hello-world"}

### ページとの使用方法

[`pages/`](/docs/guide/directory-structure/pages) ディレクトリがある場合、現在のページを表示するために [`<NuxtPage>`](/docs/api/components/nuxt-page) コンポーネントを使用する必要があります：

```vue [app.vue]
<template>
  <NuxtPage />
</template>
```

`app.vue` でアプリケーションの共通構造を直接定義することもできます。これは、ヘッダーやフッターなどのグローバル要素を含めたい場合に便利です：

```vue [app.vue]
<template>
  <header>
    ヘッダーコンテンツ
  </header>
  <NuxtPage />
  <footer>
    フッターコンテンツ
  </footer>
</template>
```

::note
`app.vue` は Nuxt アプリケーションのメインコンポーネントとして機能することを覚えておいてください。そこに追加したもの（JS と CSS）はグローバルになり、すべてのページに含まれます。
::

::read-more{to="/docs/guide/directory-structure/pages"}
`pages/` ディレクトリを使用してページを構造化する方法について詳しく学ぶ。
::

### レイアウトとの使用方法

アプリケーションが異なるページに対して異なるレイアウトを必要とする場合、[`<NuxtLayout>`](/docs/api/components/nuxt-layout) コンポーネントで `layouts/` ディレクトリを使用できます。これにより、複数のレイアウトを定義し、ページごとに適用できます。

```vue [app.vue]
<template>
  <NuxtLayout>
    <NuxtPage />
  </NuxtLayout>
</template>
```

::read-more{to="/docs/guide/directory-structure/layouts"}
`layouts/` ディレクトリを使用してレイアウトを構造化する方法について詳しく学ぶ。
::
