パッケージマネージャー（[`npm`](https://docs.npmjs.com/cli/commands/npm)、[`yarn`](https://yarnpkg.com)、[`pnpm`](https://pnpm.io/cli/install)、[`bun`](https://bun.sh/package-manager)）がプロジェクトの依存関係を保存するためにこのディレクトリを作成します。

::important
このディレクトリは、依存関係をリポジトリにプッシュすることを避けるために、[`.gitignore`](/docs/guide/directory-structure/gitignore) ファイルに追加する必要があります。
::
