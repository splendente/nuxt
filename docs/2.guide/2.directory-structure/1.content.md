[Nuxt Content](https://content.nuxt.com) はプロジェクト内の [`content/` ディレクトリ](/docs/guide/directory-structure/content)を読み取り、`.md`、`.yml`、`.csv`、`.json` ファイルを解析してアプリケーション用のファイルベース CMS を作成します。

- 組み込みコンポーネントでコンテンツをレンダリング。
- MongoDB のような API でコンテンツをクエリ。
- MDC 構文で Markdown ファイル内で Vue コンポーネントを使用。
- ナビゲーションの自動生成。

::read-more{to="https://content.nuxt.com" target="_blank"}
**Nuxt Content** ドキュメントで詳しく学ぶ。
::

## Nuxt Content の有効化

プロジェクトに `@nuxt/content` モジュールをインストールし、`nuxt.config.ts` に追加するところまでを 1 つのコマンドで行います：

```bash [Terminal]
npx nuxt module add content
```

## コンテンツの作成

Markdown ファイルを `content/` ディレクトリ内に配置します：

```md [content/index.md]
# Hello Content
```

モジュールが自動的に読み込み、解析します。

## コンテンツのレンダリング

コンテンツページをレンダリングするには、[`<ContentRenderer>`](https://content.nuxt.com/docs/components/content-renderer) コンポーネントを使用して [キャッチオールルート](/docs/guide/directory-structure/pages/#catch-all-route)を追加します：

```vue [pages/[...slug\\].vue]
<script lang="ts" setup>
const route = useRoute()
const { data: page } = await useAsyncData(route.path, () => {
  return queryCollection('content').path(route.path).first()
})
</script>

<template>
  <div>
    <header><!-- ... --></header>

    <ContentRenderer v-if="page" :value="page" />

    <footer><!-- ... --></footer>
  </div>
</template>
```
