`.nuxtrc` ファイルは、フラットな構文で Nuxt を設定するために使用できます。これは [`unjs/rc9`](https://github.com/unjs/rc9) をベースにしています。

::tip
より高度な設定については、[`nuxt.config`](/docs/guide/directory-structure/nuxt-config) を使用してください。
::

## 使用方法

```bash [.nuxtrc]
# SSR を無効化
ssr=false

# `@nuxt/devtools` の設定
devtools.enabled=true

# Nuxt モジュールを追加
modules[]=@nuxt/image
modules[]=nuxt-security
```

存在する場合、`nuxt.config` ファイル内のプロパティは `.nuxtrc` ファイル内のプロパティを上書きします。

::read-more{to="/docs/api/configuration/nuxt-config"}
**Nuxt 設定**ドキュメントで利用可能なすべてのオプションを確認してください。
::

## グローバル `.nuxtrc` ファイル

ホームディレクトリにグローバル `.nuxtrc` ファイルを作成して、設定をグローバルに適用することもできます。

- macOS/Linux では、このファイルは次の場所にあります：

  ```md
  ~/.nuxtrc
  ```

- Windows では、次の場所にあります：

  ```md
  C:\Users\{username}\.nuxtrc
  ```

このグローバル `.nuxtrc` ファイルを使用すると、システム上のすべての Nuxt プロジェクトに適用されるデフォルト設定を定義できます。ただし、プロジェクトレベルの `.nuxtrc` ファイルはこれらのグローバル設定を上書きし、`nuxt.config` は両方よりも優先されます。
