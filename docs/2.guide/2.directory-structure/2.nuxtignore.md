`.nuxtignore` ファイルは、ビルド段階で Nuxt がプロジェクトのルートディレクトリ（[`rootDir`](/docs/api/nuxt-config#rootdir)）内のファイルを無視するように指示します。

このファイルは [`.gitignore`](/docs/guide/directory-structure/gitignore) や `.eslintignore` ファイルと同じ仕様に従い、各行は無視するファイルを示す glob パターンです。

::tip
`nuxt.config` ファイルで [`ignoreOptions`](/docs/api/nuxt-config#ignoreoptions)、[`ignorePrefix`](/docs/api/nuxt-config#ignoreprefix)、[`ignore`](/docs/api/nuxt-config#ignore) を設定することもできます。
::

## 使用方法

```bash [.nuxtignore]
# レイアウト foo.vue を無視
app/layouts/foo.vue
# 名前が -ignore.vue で終わるレイアウトファイルを無視
app/layouts/*-ignore.vue

# ページ bar.vue を無視
app/pages/bar.vue
# ignore フォルダ内のページを無視
app/pages/ignore/*.vue

# foo フォルダ下のルートミドルウェアファイルを無視（foo/bar.js を除く）
app/middleware/foo/*.js
!app/middleware/foo/bar.js
```

::read-more{icon="i-simple-icons-git" title="git ドキュメント" to="https://git-scm.com/docs/gitignore" target="_blank"}
仕様の詳細は **gitignore ドキュメント**で確認できます。
::
