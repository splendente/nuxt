`nuxt.config` ファイルの拡張子は `.js`、`.ts`、または `.mjs` のいずれかにできます。

```ts twoslash [nuxt.config.ts]
export default defineNuxtConfig({
  // My Nuxt config
})
```

::tip
`defineNuxtConfig` ヘルパーはインポートなしでグローバルに利用できます。
::

お好みの場合は、`nuxt/config` から `defineNuxtConfig` を明示的にインポートできます：

```ts twoslash [nuxt.config.ts]
import { defineNuxtConfig } from 'nuxt/config'

export default defineNuxtConfig({
  // My Nuxt config
})
```

::read-more{to="/docs/api/configuration/nuxt-config"}
**Nuxt 設定**ドキュメントで利用可能なすべてのオプションを確認してください。
::

設定が最新の状態であることを確実にするため、Nuxt はメインの設定ファイル、[`.env`](/docs/guide/directory-structure/env)、[`.nuxtignore`](/docs/guide/directory-structure/nuxtignore)、[`.nuxtrc`](/docs/guide/directory-structure/nuxtrc) ドットファイルの変更を検出すると完全な再起動を行います。
