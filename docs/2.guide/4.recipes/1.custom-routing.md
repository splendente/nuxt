## カスタムルートの追加

Nuxt では、ルーティングは [pages ディレクトリ](/docs/guide/directory-structure/pages)内のファイル構造によって定義されます。しかし、内部で [vue-router](https://router.vuejs.org) を使用しているため、Nuxt はプロジェクトにカスタムルートを追加するいくつかの方法を提供します。

### ルーター設定

[ルーターオプション](/docs/guide/recipes/custom-routing#router-options)を使用して、スキャンされたルートを受け取り、カスタマイズされたルートを返す関数を使用して、ルートをオプションでオーバーライドまたは拡張できます。

`null` または `undefined` を返す場合、Nuxt はデフォルトルートにフォールバックします（入力配列を変更するのに便利）。

```ts [router.options.ts]
import type { RouterConfig } from '@nuxt/schema'

export default {
  // https://router.vuejs.org/api/interfaces/routeroptions.html#routes
  routes: (_routes) => [
    {
      name: 'home',
      path: '/',
      component: () => import('~/pages/home.vue')
    }
  ],
} satisfies RouterConfig
```

::note
Nuxt は、`routes` 関数から返される新しいルートを、提供されたコンポーネントの `definePageMeta` で定義されたメタデータで拡張しません。それを実現したい場合は、[ビルド時に呼び出される](/docs/api/advanced/hooks#nuxt-hooks-build-time) `pages:extend` フックを使用する必要があります。
::

### Pages フック

`pages:extend` Nuxt フックを使用して、スキャンされたルートからページを追加、変更、または削除できます。

例えば、`.ts` ファイルのルートの作成を防ぐには：

```ts [nuxt.config.ts]
import type { NuxtPage } from '@nuxt/schema'

export default defineNuxtConfig({
  hooks: {
    'pages:extend' (pages) {
      // add a route
      pages.push({
        name: 'profile',
        path: '/profile',
        file: '~/extra-pages/profile.vue'
      })

      // remove routes
      function removePagesMatching (pattern: RegExp, pages: NuxtPage[] = []) {
        const pagesToRemove: NuxtPage[] = []
        for (const page of pages) {
          if (page.file && pattern.test(page.file)) {
            pagesToRemove.push(page)
          } else {
            removePagesMatching(pattern, page.children)
          }
        }
        for (const page of pagesToRemove) {
          pages.splice(pages.indexOf(page), 1)
        }
      }
      removePagesMatching(/\.ts$/, pages)
    }
  }
})
```

### Nuxt モジュール

特定の機能に関連するページのセット全体を追加する予定の場合は、[Nuxt モジュール](/modules)を使用することをお勧めします。

[Nuxt kit](/docs/guide/going-further/kit) は[ルートを追加する](/docs/api/kit/pages)いくつかの方法を提供します：
- [`extendPages`](/docs/api/kit/pages#extendpages) (callback: pages => void)
- [`extendRouteRules`](/docs/api/kit/pages#extendrouterules) (route: string, rule: NitroRouteConfig, options: ExtendRouteRulesOptions)

## ルーターオプション

[`vue-router`](https://router.vuejs.org/api/interfaces/routeroptions.html) のオプションをカスタマイズするのに加えて、Nuxt はルーターをカスタマイズするための[追加オプション](/docs/api/nuxt-config#router)を提供します。

### `router.options` の使用

これは[ルーターオプション](/docs/api/nuxt-config#router)を指定するための推奨方法です。

```ts [router.options.ts]
import type { RouterConfig } from '@nuxt/schema'

export default {
} satisfies RouterConfig
```

`pages:routerOptions` フック内にファイルを追加することで、さらにルーターオプションファイルを追加することができます。配列の後のアイテムは前のアイテムをオーバーライドします。

::callout
このフックでルーターオプションファイルを追加すると、`optional` が設定されていない限り、ページベースのルーティングが有効になります。`optional` が設定されている場合、ページベースのルーティングがすでに有効になっている場合にのみ適用されます。
::

```ts [nuxt.config.ts]
import { createResolver } from '@nuxt/kit'

export default defineNuxtConfig({
  hooks: {
    'pages:routerOptions' ({ files }) {
      const resolver = createResolver(import.meta.url)
      // ルートを追加
      files.push({
        path: resolver.resolve('./runtime/router-options'),
        optional: true
      })
    }
  }
})
```

### `nuxt.config` の使用

**注意：** JSON シリアライズ可能な[オプション](/docs/api/nuxt-config#router)のみが設定可能です：

- `linkActiveClass`
- `linkExactActiveClass`
- `end`
- `sensitive`
- `strict`
- `hashMode`
- `scrollBehaviorType`

```js [nuxt.config]
export default defineNuxtConfig({
  router: {
    options: {}
  }
})
```

### ハッシュモード（SPA）

`hashMode` [設定](/docs/api/nuxt-config#router)を使用して SPA モードでハッシュ履歴を有効にできます。このモードでは、ルーターは内部で渡される実際の URL の前にハッシュ文字（#）を使用します。有効にすると、**URL はサーバーに送信されることはなく**、**SSR はサポートされません**。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  ssr: false,
  router: {
    options: {
      hashMode: true
    }
  }
})
```

### ハッシュリンクのスクロール動作

ハッシュリンクのスクロール動作をオプションでカスタマイズできます。[設定](/docs/api/nuxt-config#router)を `smooth` に設定し、ハッシュリンクのあるページ（例：`https://example.com/blog/my-article#comments`）を読み込むと、ブラウザーがこのアンカーまでスムーズにスクロールすることがわかります。

```ts [nuxt.config.ts]
export default defineNuxtConfig({
  router: {
    options: {
      scrollBehaviorType: 'smooth'
    }
  }
})
```

#### カスタム履歴（上級）

ベース URL を受け取り、履歴モードを返す関数を使用して、履歴モードをオプションでオーバーライドできます。`null` または `undefined` を返す場合、Nuxt はデフォルトの履歴にフォールバックします。

```ts [router.options.ts]
import type { RouterConfig } from '@nuxt/schema'
import { createMemoryHistory } from 'vue-router'

export default {
  // https://router.vuejs.org/api/interfaces/routeroptions.html
  history: base => import.meta.client ? createMemoryHistory(base) : null /* default */
} satisfies RouterConfig
```
